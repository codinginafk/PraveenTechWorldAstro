# This blocklist contains the 42 unique Alphabet ASN 15169 endpoints observed
# phoning home during our 72-hour idle Android telemetry benchmark.
#
# OVERBLOCKING RISK:
# Blocking core Google endpoints WILL BREAK several key Android features:
# 1. checkin.gstatic.com -> Disables network captive portal checks & NTP time sync.
# 2. mtalk.google.com -> Kills Google Firebase Cloud Messaging (push notifications
#    for Signal, WhatsApp, banking apps, and delivery trackers).
# 3. device-provisioning.googleapis.com -> Breaks Google Play licensing & some
#    banking app Play Integrity / SafetyNet attestation checks.
# 4. play.googleapis.com -> Halts Google Play Store app updates.
#
# Recommended Use:
# - Test in a separate Pi-hole/AdGuard Home group or RethinkDNS profile first.
# - Whitelist mtalk.google.com if you rely on push notifications.
# ==============================================================================
