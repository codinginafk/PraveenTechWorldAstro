Windows 11 volume slider not working? If the slider is frozen, restart Windows Audio and Windows Audio Endpoint Builder, then restart Explorer if the taskbar is also stuck. If the slider moves but there is no sound, check the output device and Volume mixer first. These symptoms can have different causes.

Microsoft’s audio guidance starts with the selected output, the Get Help troubleshooter, audio enhancements, and drivers. A stuck slider can also involve Windows Audio services or the Explorer shell, so the safest order is to test the least destructive fixes first.

Use the symptom table below, then work through the fixes in order. None of them requires reinstalling Windows as a first step.

---

## Restart the Windows audio services

If the slider freezes or audio stopped after sleep or an update, restart the two Windows audio services. Open **PowerShell as Administrator** and run:

```powershell
# Restart the Windows audio services
Restart-Service -Name "AudioEndpointBuilder" -Force
Restart-Service -Name "Audiosrv" -Force
```

This restarts only the audio services; it does not terminate Explorer or close your open windows. If the audio slider is still frozen while the rest of the taskbar is also unresponsive, restart **Windows Explorer** separately from Task Manager. If this helps only until the next sleep or reboot, continue with the driver and power-state checks below.

## Quick diagnostic matrix: match your symptom

| Symptom | Primary Root Cause | Fast 1-Minute Fix |
|:---|:---|:---|
| **Slider moves, but no sound plays** | Output device mismatch or sample rate lock | Change default format to `24-bit, 48000 Hz` |
| **Slider frozen or grayed out** | `AudioEndpointBuilder` service hung after sleep | Run PowerShell service restart command |
| **Volume icon missing from taskbar** | Taskbar notification area cache corruption | Reset Explorer shell & re-enable system icons |
| **Red 'X' on speaker icon** | Audio driver disabled or uninstalled | Re-enable device in `devmgmt.msc` |
| **Volume changes automatically** | Communications attenuation enabled | Set 'When Windows detects communication activity' to 'Do nothing' |

## Step-by-step fixes for an unresponsive volume control

### Fix 1: Restart Windows Audio and Endpoint Builder

Windows 11 uses two linked services for playback: `Audiosrv` (Windows Audio) and `AudioEndpointBuilder` (Windows Audio Endpoint Builder). Restarting them is a reversible test when the slider or output device stops responding.

1. Press **Ctrl + Shift + Esc** to open **Task Manager**.
2. Switch to the **Services** tab.
3. Locate **AudioEndpointBuilder** and **Audiosrv**.
4. Right-click **AudioEndpointBuilder** and select **Restart**.
5. Right-click **Audiosrv** and select **Restart**.

```powershell
# Alternative: Execute directly via PowerShell (Admin)
Restart-Service -Name "AudioEndpointBuilder" -Force
Restart-Service -Name "Audiosrv" -Force
```

---

### Fix 2: Reset Windows Explorer Shell

The taskbar volume slider is drawn by the Windows Explorer process (`explorer.exe`). If the shell's XAML interface crashes, the slider becomes non-interactive.

1. Open **Task Manager** (**Ctrl + Shift + Esc**).
2. Under the **Processes** tab, scroll down to **Windows Explorer**.
3. Right-click **Windows Explorer** and select **Restart**.
4. Your screen will flicker for 2–3 seconds as the taskbar reloads.

---

### Fix 3: Run the audio troubleshooter in Get Help

Microsoft now directs Windows 11 users to the audio troubleshooter in the **Get Help** app. Open Get Help, search for **audio troubleshooter**, and allow it to inspect the device. You can also open **Settings > System > Troubleshoot > Other troubleshooters > Audio > Run** when that option is available.

The older `msdt.exe` command is deprecated. Do not make it the main path in a current Windows 11 guide.

---

### Fix 4: Roll Back or Reinstall Audio Drivers

After an update, an audio driver can be incompatible, partially installed, or replaced with a generic driver that does not expose the expected controls. Compare the installed version with the PC manufacturer's support page.

1. Press **Windows Key + X** and select **Device Manager** (`devmgmt.msc`).
2. Expand **Sound, video and game controllers**.
3. Right-click your audio device (e.g., *Realtek High Definition Audio*) and select **Properties**.
4. Navigate to the **Driver** tab:
   - If **Roll Back Driver** is available, click it to revert to your previous working driver.
   - If unavailable, click **Uninstall Device**, check *Attempt to remove the driver for this device*, and click **Uninstall**.
5. Reboot your PC. Windows will automatically reinstall the clean factory driver on startup.

---

### Fix 5: Adjust Default Sound Format & Sample Rate

If the slider moves but the selected device produces no sound, test a standard format after checking the output and app mixer. Some drivers and external DACs do not handle every available format reliably.

1. Press **Windows Key + R**, type `mmsys.cpl`, and press **Enter** to open classic Sound Control Panel.
2. Under the **Playback** tab, double-click your default playback device.
3. Switch to the **Advanced** tab.
4. Set the Default Format drop-down to **24-bit, 48000 Hz (Studio Quality)** or **16-bit, 44100 Hz (CD Quality)**.
5. Click **Test**. If you hear the chime, click **Apply** and **OK**.

---

### Fix 6: Disable Audio Enhancements & Spatial Sound

Software enhancements (Dolby Atmos, DTS Sound Unbound, spatial audio drivers) can lock the volume control endpoint.

1. Open `mmsys.cpl` via Run (**Win + R**).
2. Double-click your active playback device.
3. Switch to the **Enhancements** tab (or **Signal Enhancements** on newer drivers).
4. Check **Disable all enhancements** (or turn off *Enable audio enhancements*).
5. Switch to the **Spatial sound** tab and set Spatial sound format to **Off**.
6. Click **Apply** and test your volume slider.

---

### Fix 7: Reset Volume Mixer & App Volume Preferences

If specific applications (e.g., Chrome, Spotify, games) are muted while system sounds work, your Windows 11 App Volume Mixer may be corrupted.

Launch the App Volume settings page directly:

```powershell
# Open Windows 11 Volume Mixer settings directly
Start-Process "ms-settings:apps-volume"
```

Scroll to the bottom of the page and click **Reset** under *Reset sound devices and volumes for all apps to the recommended defaults*.

---

### Fix 8: Repair System File Corruption (SFC & DISM)

If the audio problem appears alongside wider Windows errors, run System File Checker and DISM from an elevated terminal:

```powershell
# Run in PowerShell (Admin)
sfc /scannow
dism /online /cleanup-image /restorehealth
```

Allow both commands to complete 100%. If SFC reports *"Windows Resource Protection found corrupt files and successfully repaired them"*, reboot your machine.

## If the volume slider sticks after sleep

If the volume control freezes **only after waking your laptop from sleep**, compare a normal restart, the audio-driver state, and the power settings before changing anything permanently.

**Use Fast Startup as a temporary comparison:**

1. Press **Win + R**, type `control powercfg.cpl`, and hit **Enter**.
2. Click **Choose what the power buttons do** on the left menu.
3. Click **Change settings that are currently unavailable**.
4. Uncheck **Turn on fast startup (recommended)**.
5. Click **Save changes**.

Restart and test the same output device again. If the symptom changes, the power-state path is worth investigating with the PC manufacturer's chipset and audio drivers. Re-enable the setting if it does not help.
