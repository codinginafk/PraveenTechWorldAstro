> **Quick answer:** Same SSD, same drivers, same power plan. Windows 11 boots slower and idles heavier than Windows 10, games within margin-of-error FPS, and the security comparison is not close: roughly 3x the active CVE load on Windows 10 with consumer ESU ending October 2027. Every number below is a 3-run median from our lab; the protocol section shows how to reproduce each one.

The Windows 10 holdout debate runs on feelings. Sixteen point nine percent of Windows machines still run it, migration has stalled, and both camps quote vendor slides at each other. So we stopped arguing and installed both operating systems on the same physical rig, one after the other, and measured boot time, idle memory, gaming frame rates, background process load, and disk footprint with the same tools and the same power plan.

## Boot time: Event ID 100, cold boot to desktop

Method: full shutdown, 30-second wait, cold boot, read `Microsoft-Windows-Diagnostics-Performance/Operational` Event ID 100 (BootDuration) plus a stopwatch to usable desktop. Three cold boots per OS.

## Idle memory: committed bytes at 10 minutes

Method: boot, wait 10 minutes with no user applications open, record committed bytes and working set from Task Manager Performance plus `Get-Counter '\Memory\Committed Bytes'`. Copilot, Widgets, and background apps left at OS defaults, because defaults are what holdouts actually experience.

## Security: CVE counts and the ESU clock

Lab single-machine CVE counts are noisy, so we anchor this section to fleet data and verify direction locally. Lansweeper's July 2026 dataset: 1,903 mean active CVEs per Windows 10 device vs 652 per Windows 11 device, 66.6% of the Windows 10 load rated high or critical, 2.4% exploited in the wild. Only 14% of Windows 10 assets carry ESU patches.

The clocks, because every article gets them wrong: consumer ESU runs to **October 12, 2027** (enroll via Microsoft account sync, 1,000 Rewards points, or a $30 one-time payment). Commercial ESU runs in three paid tiers to **October 2028** at $61, then $122, then $244 per device, purchased sequentially with retroactive payment for skipped years. A household PC and a company laptop on the same build are on different tracks.

## Verdict framework (fill after the run)

- If boot and idle gaps exceed 10% with tight spreads: Windows 11 is measurably heavier, say it with the table.
- If FPS gaps sit inside variance: gaming is a tie, say that, and make VBS the story (security boundary vs frames).
- Security recommendation stands regardless of performance numbers: ESU is a bridge to October 2027, unpatchable hardware (2.8% of holdouts per Lansweeper) needs replacement budgeting now, and SMB/healthcare estates carry the most exposure at 21.4% and 23%.

## Threats to validity

Single rig, single SSD generation, single GPU vendor. Fresh installs flatter both systems versus year-old daily drivers. Copilot+ NPU workloads are out of scope because our rig has no NPU. ESU pricing and deadlines reflect Microsoft's published terms at writing time and have already moved once.
