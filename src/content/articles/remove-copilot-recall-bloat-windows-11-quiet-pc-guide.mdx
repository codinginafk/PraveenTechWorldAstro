> **Quick answer:** Uninstall the Microsoft Copilot app under Settings > Apps, switch Recall snapshots off under Privacy & security, then clear leftover entry points with Group Policy on Pro and higher editions or PowerShell elsewhere. Confirm the cleanup in `services.msc` and Task Manager Startup. The whole pass takes about 15 minutes and every step is reversible.

In January 2026, Microsoft started retreating from its own AI push. Copilot integrations in Notepad, Paint, Photos, Snipping Tool, and Widgets went under review for removal. Work on new Copilot buttons paused. Recall — the screenshot-every-few-seconds flagship of Copilot+ PCs — was internally judged a failure in its current form. Then the March quality pledge added the rest: taskbar repositioning back after four years, a single monthly reboot model, and shutdown without forced patch installs.

Our lab position is simple. We do not hate AI features. We hate AI features we cannot remove, audit, or keep off after an update. This guide strips the Copilot layer, the Recall layer, and the upsell layer, in that order, and shows you how to confirm each one is actually gone instead of trusting a toggle.

## Before you start: inventory what is installed

Open elevated PowerShell and list every Copilot-related package on the machine:

```powershell
Get-AppxPackage -Name "*Copilot*" | Select-Object Name, Version
Get-AppxPackage -Name "*Recall*" | Select-Object Name, Version
```

Write down what comes back. Most machines show the Microsoft Copilot app plus Copilot entry points inside inbox apps. Recall appears only on Copilot+ hardware, and only if someone opted in. If the list is empty, your machine is already clean and you can skip to the verification section.

## Method 1: Settings (all editions, 5 minutes)

1. Open **Settings > Apps > Installed apps**, search for Copilot, open the three-dot menu, and uninstall the Microsoft Copilot app.
2. Open **Settings > Personalization > Taskbar** and switch the Copilot toggle off. The taskbar button disappears immediately, no restart needed.
3. Open **Settings > Privacy & security > Recall & snapshots** and confirm snapshots are off. If the page says Recall is not available on this device, you are done with this layer.
4. Open Notepad, Paint, and Photos, and check each app's settings or menu for a Copilot entry. Where one exists, switch it off inside the app. Microsoft's March pledge targets exactly these integrations, but removal is rolling out gradually, so check manually after every feature update.

## Method 2: Group Policy (Pro, Enterprise, Education)

Build 26220.7535 (KB5072046) added a dedicated policy: **RemoveMicrosoftCopilotApp**, under User Configuration > Administrative Templates > Windows AI. Enabling it uninstalls the consumer Copilot app on managed devices, with three conditions straight from Microsoft's documentation: the device must have both Microsoft 365 Copilot and the consumer Copilot app installed, the app must not have been installed by the user, and it must not have launched in the past 28 days. Microsoft 365 Copilot keeps working.

Home edition has no Group Policy editor. Do not install third-party gpedit cloners from forums; use Method 1 plus Method 3 instead. The registry equivalents of AI policies live under version-specific keys that Microsoft renames, which is why this guide does not print them.

## Method 3: PowerShell removal and startup cleanup

For leftover Appx packages, remove per-package after confirming the exact name from the inventory step:

```powershell

```

Then open Task Manager > Startup apps and disable every Copilot, Recall, and feedback-related entry. Open `services.msc` and confirm no Copilot-connected service is set to Automatic on a machine where you removed the app. Reboot once. Re-run the inventory command from the top of this guide; it should return nothing.

## Calm Windows Update down while you are here

The same March pledge that cut Copilot entry points changed update behavior. Open **Settings > Windows Update > Advanced options** and set longer pause windows and active hours that match your workday. Shutdown and restart no longer force pending patch installs first, and Microsoft is moving toward a single monthly reboot model. After each Patch Tuesday, spend two minutes re-checking the Copilot entries from Method 1; feature updates remain the main way removed integrations come back.

## Confirm it is actually gone

1. The inventory PowerShell command returns nothing.
2. Task Manager Startup shows no Copilot or Recall entries.
3. `services.msc` shows no Copilot service on Automatic.
4. Settings search for "Copilot" returns only Microsoft 365 or Edge results, not OS entry points.
5. Disk check: inbox app reinstalls after a feature update are the number one resurrection path, so repeat this checklist after every major update, not just once.

## What stays, deliberately

Microsoft 365 Copilot if you pay for it. Windows Security, SmartScreen, and Defender telemetry controls — removing security posture to save 200MB of RAM is a bad trade and this guide does not do it. OneDrive sync settings, which are a separate battle under Accounts > Windows backup. And the Feedback Hub, which costs nothing when notifications are off and is genuinely useful for upvoting the taskbar and update fixes you want Microsoft to keep.
