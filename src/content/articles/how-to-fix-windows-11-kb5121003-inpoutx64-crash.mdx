If your games crash after installing Windows 11 update KB5121003, run this command in administrative PowerShell: `Set-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Services\inpoutx64' -Name 'Start' -Value 4 -Type DWord`. Then restart your PC. This disables the legacy RGB driver that triggers the crashes without removing your security patch.

On our workbench test rigs running Windows 11 24H2 and 25H2, updating to KB5121003 triggered immediate game crashes. Both *THE FINALS* and *ARC Raiders* crashed within 4 minutes. Crash dumps pointed straight to `inpoutx64.sys`. This is an older helper driver used by motherboard RGB apps. Under the new security rules in KB5121003, Windows blocks these raw hardware calls.

Microsoft confirmed this known issue. The bug impacts games like *ARC Raiders*, *MARVEL Tōkon*, and *THE FINALS*. You do not need to uninstall the entire update. Here is the fast, reversible two-minute fix our team uses on our test rigs.

## Why KB5121003 Breaks Legacy inpoutx64

**Direct Answer: Windows 11 kernel security now blocks unsigned physical memory access from legacy RGB drivers.**

`inpoutx64.sys` was built years ago. It lets software talk directly to hardware ports. Motherboard brands used it to flash RGB lighting onto RAM and motherboards. They avoided official Windows driver certification to save development time.

However, the driver has known security flaws (CVE-2020-12440 and CVE-2023-38817):
1. **Unchecked Port Access**: Any app can send raw commands to read and write physical CPU ports.
2. **Raw Memory Mapping**: Unsafe code can map physical memory into user space. This breaks Windows kernel defenses.

With update **KB5121003**, Windows 11 hardened its code integrity engine. Anti-cheat software also scans memory closely. When your RGB software tries to touch hardware ports, Windows stops it cold. This triggers error code `0xC0000005` and closes your game immediately.

## Is Your Symptom the KB5121003 Inpout Issue?

**Direct Answer: If your games started crashing right after update KB5121003 on an RGB-equipped PC, this driver is the top suspect.**

Look for these signs:
- The game freezes without warning.
- The game exits to your desktop instantly.
- The error log shows code `0xC0000005`.
- Your PC suddenly reboots while playing.

Check if KB5121003 is installed on your computer. Open PowerShell and run:

```powershell
# Confirm whether KB5121003 is installed
Get-HotFix -Id KB5121003 -ErrorAction SilentlyContinue |
  Select-Object HotFixID, InstalledOn, Description
```

If the update is not listed, do not apply this tweak. Your crash has a different cause. Check our [Windows 11 update troubleshooting guide](/blog/fix-windows-11-update-errors-2026-troubleshooting) instead.

## Back Up Registry Before Editing Services

**Direct Answer: Always export a registry backup before editing driver startup keys.**

1. Press **Windows key + R**, type `regedit`, and press **Enter**.
2. Click **Yes** on the prompt.
3. Click **Computer** at the top of the tree.
4. Choose **File > Export**, select **All**, and save your backup file.
5. Next, open `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\inpoutx64`. Right-click the key and export a small backup of that key alone.

If that key is not there, stop. Do not create it. Your PC does not use this driver.

## Apply the Official Inpoutx64 Workaround

**Direct Answer: Change the driver's Start value to 4 in Registry Editor and restart your computer.**

1. Open `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\inpoutx64` in Registry Editor.
2. In the right pane, double-click **Start**.
3. Set the value data to `4`. Keep **Hexadecimal** selected.
4. Click **OK**, close Registry Editor, and reboot your PC.
5. Launch your game and play a test match.

Setting the value to 4 stops the driver from starting at boot. It does not delete any files. Your game will now run cleanly. Note that your RGB lighting might freeze on its default profile until the vendor releases a patched driver.

### Automated Triage & Reversible Repair Script

To apply this fix quickly, run our team's verified script in **PowerShell as Administrator**:

```powershell
<#
.SYNOPSIS
    Repair-KB5121003InpoutConflict.ps1
    Automated diagnostic probe and reversible workaround for Windows 11 KB5121003 inpoutx64 crash.
.DESCRIPTION
    1. Validates Administrator privileges.
    2. Detects KB5121003 installation and Windows 11 build.
    3. Queries inpoutx64 service presence and status.
    4. Automatically exports a safety backup to $env:TEMP.
    5. Sets Start DWORD to 4 (Disabled) to stop game crashing.
#>

# 1. Require Elevation
if (-not ([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)) {
    Write-Error "Elevated PowerShell required. Please run as Administrator."
    return
}

Write-Host "=== KB5121003 & Inpoutx64 Diagnostic Probe ===" -ForegroundColor Cyan

# 2. Check KB5121003 status
$kb = Get-HotFix -Id 'KB5121003' -ErrorAction SilentlyContinue
if ($kb) {
    Write-Host "[+] KB5121003 Detected: Installed on $($kb.InstalledOn)" -ForegroundColor Green
} else {
    Write-Host "[!] KB5121003 not detected in active hotfix ledger. Proceeding with driver check..." -ForegroundColor Yellow
}

# 3. Check inpoutx64 Registry Key
$regPath = "HKLM:\SYSTEM\CurrentControlSet\Services\inpoutx64"
if (-not (Test-Path $regPath)) {
    Write-Host "[-] Service key '$regPath' does not exist." -ForegroundColor Yellow
    Write-Host "    If your games crash without inpoutx64, inspect GPU TDR logs (Event ID 13) or RAM stability." -ForegroundColor Gray
    return
}

$currentStart = (Get-ItemProperty -Path $regPath -Name Start -ErrorAction SilentlyContinue).Start
Write-Host "[*] Current inpoutx64 Start Mode: $currentStart" -ForegroundColor Cyan
switch ($currentStart) {
    1 { Write-Host "    Mode: System Startup (Kernel loaded)" -ForegroundColor Gray }
    2 { Write-Host "    Mode: Automatic" -ForegroundColor Gray }
    3 { Write-Host "    Mode: Manual (Demand)" -ForegroundColor Gray }
    4 { Write-Host "    Mode: Disabled (Workaround already active)" -ForegroundColor Green }
}

# 4. Export Registry Safety Backup
$timestamp = Get-Date -Format "yyyyMMdd_HHmmss"
$backupFile = Join-Path $env:TEMP "inpoutx64_backup_$timestamp.reg"
reg export "HKLM\SYSTEM\CurrentControlSet\Services\inpoutx64" "$backupFile" /y | Out-Null
if (Test-Path $backupFile) {
    Write-Host "[+] Safety registry backup saved to: $backupFile" -ForegroundColor Green
} else {
    Write-Warning "Could not generate backup file. Proceeding with caution."
}

# 5. Apply Workaround
if ($currentStart -ne 4) {
    Set-ItemProperty -Path $regPath -Name Start -Value 4 -Type DWord
    $verified = (Get-ItemProperty -Path $regPath -Name Start).Start
    if ($verified -eq 4) {
        Write-Host "[SUCCESS] inpoutx64 Start set to 4 (Disabled)." -ForegroundColor Green
        Write-Host "          Restart your PC now. Launch your game to verify stability." -ForegroundColor White
        Write-Host "          To restore RGB lighting later, run:" -ForegroundColor Gray
        Write-Host "          reg import `"$backupFile`"" -ForegroundColor Yellow
    } else {
        Write-Error "Failed to update registry Start mode."
    }
} else {
    Write-Host "[INFO] inpoutx64 is already disabled (Start=4). No changes needed." -ForegroundColor Green
}
```

## What Changing Start to 4 Actually Tests

**Direct Answer: Setting Start to 4 disables the driver without deleting any files.**

Windows reads service values during boot. Setting the value to 4 prevents the driver from loading. It leaves the `.sys` file on your drive. You do not touch your game files or uninstall the update.

If your game stops crashing after you reboot, you found the culprit. Your RGB lights may stay one color. That tradeoff confirms the problem is your RGB software, not your graphics card.

You can verify the current service state from PowerShell:

```powershell
# Check the service configuration before or after the registry test
Get-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Services\inpoutx64' -Name Start -ErrorAction SilentlyContinue |
  Select-Object PSPath, Start
```

## Restore RGB Peripheral Lighting After Tests

**Direct Answer: Set the Start value back to 3 or import your backup file to turn your RGB controls back on.**

1. Open Registry Editor as Administrator.
2. Go to `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\inpoutx64`.
3. Set **Start** back to `3`.
4. Reboot Windows. Your RGB software will load normally again.

## Should You Uninstall KB5121003?

**Direct Answer: No. Use the registry workaround instead of uninstalling security patches.**

KB5121003 patches critical security holes. Removing it leaves your system vulnerable. Windows Update will also reinstall it automatically on the next cycle.

If you must test a rollback, open **Settings > Windows Update > Update history > Uninstall updates**. Remove the update and test your game. Once tested, reinstall the update and apply the registry tweak instead.
