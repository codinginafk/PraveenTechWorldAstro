## Preparing Your Debloat Toolkit: 3 Tested Ways

You can remove bloatware through three reliable methods. Choose the option matching your technical setup.

```
+-------------------------------------------------------------+
|             CHOOSE YOUR DEBLOAT WORKFLOW                    |
+-------------------------------------------------------------+
| 1. UAD-NG (Recommended for PC users: GUI, safe presets)     |
| 2. Shizuku + Canta (No PC required: 100% on-device)         |
| 3. Raw ADB Terminal (Direct terminal control: single script)|
+-------------------------------------------------------------+
```

### Way 1: Universal Android Debloater Next Generation (UAD-NG)

Universal Android Debloater Next Generation is our top desktop choice. It runs on Windows, macOS, and Linux with a clean graphical user interface.

1. Download the latest `uad-ng` executable from GitHub.
2. Download the official Google Android Platform Tools zip archive.
3. Extract `adb.exe` into the same folder as the UAD-NG binary.
4. Connect your phone via USB.
5. Tap **Allow USB Debugging** on your phone screen when prompted.
6. Launch UAD-NG. The software detects your phone model automatically.
7. Select the **Recommended** package filter to review pre-vetted safe packages.
8. Click **Uninstall** on unwanted packages. UAD-NG removes them immediately.

### Way 2: On-Device Debloating via Shizuku and Canta (No PC Required)

If you lack access to a computer, you can debloat directly on your handset. This process requires Android 11 or newer connected to Wi-Fi.

1. Install **Shizuku** and **Canta** from F-Droid or GitHub.
2. Open phone **Settings** &rarr; **Developer Options** &rarr; toggle on **Wireless Debugging**.
3. Tap **Wireless Debugging** &rarr; tap **Pair device with pairing code**.
4. Open the Shizuku app. Tap **Pairing** and enter the 6-digit code shown on screen.
5. In Shizuku, tap **Start**. Shizuku connects to the local wireless debug port.
6. Open **Canta** and grant it Shizuku authorization.
7. Canta loads your app list categorized by risk level.
8. Select bloatware apps and tap the trash icon to remove them instantly.

### Way 3: Direct Native Wireless or USB ADB Terminal

Sysadmins who prefer raw shell scripts can use terminal commands directly. 

Open PowerShell or Bash and test connectivity:

```bash
adb devices
```

To remove a package for the primary user:

```bash
adb shell pm uninstall -k --user 0 <package_name>
```

The flag `-k` preserves internal cache directories if you ever reinstall the app. The flag `--user 0` restricts removal to your active profile. The underlying system read-only partition remains unchanged.

## The Safety Net: Instant One-Line Rollback

What happens if you uninstall an app and later realize you need it? Because ADB debloating only uninstalls packages for User 0, the system APK file remains stored in the read-only partition.

You can restore any debloated package instantly without downloading anything or factory resetting.

Run this command in your terminal:

```bash
adb shell cmd package install-existing <package_name>
```

For example, to restore the Samsung Internet Browser:

```bash
adb shell cmd package install-existing com.sec.android.sbrowser
```

The app reappears in your launcher within three seconds with default settings intact.
