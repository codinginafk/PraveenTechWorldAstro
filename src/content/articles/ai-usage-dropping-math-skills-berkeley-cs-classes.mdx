## 3. Why the Chat Box Destroys Engineering Mastery

When students ask a chatbot to solve an algorithm problem, the model outputs an essay with code embedded inside markdown fences. The student skims the explanation, copies the snippet, confirms that it passes the autograder, and moves on.

This workflow fails for three reasons:

1. **Illusion of Competence:** Reading correct code creates the psychological illusion that you understand the mathematical invariant. On proctored paper exams, students couldn't derive the recurrence relations from scratch.
2. **Context Bloat & Token Waste:** Pasting multi-turn conversational histories consumes thousands of tokens per question, causing models to lose focus on earlier constraints.
3. **No Execution Guarantee:** A conversational model cannot run code. It generates what *looks* like working Python, leaving the human to discover syntax or algorithmic errors manually.

By contrast, the Berkeley architecture forces the LLM to output a task graph, execute code in a real interpreter, verify test assertions, and log all execution states in SQLite.

## 4. Production-Ready Sandboxed Agent Script (`agent_sandbox.py`)

**Save this script as `scripts/agent_sandbox.py`. It requires only Python 3.8+ standard libraries and your OpenRouter or OpenAI API key:**

```python
#!/usr/bin/env python3
"""
scripts/agent_sandbox.py
Production-ready autonomous task planner, sandboxed code executor,
and SQLite state manager.
Requires: Python 3.8+ (Zero external dependencies)
"""

import os
import sys
import json
import sqlite3
import subprocess
import urllib.request
import urllib.error
from datetime import datetime

API_KEY = os.environ.get("OPENROUTER_API_KEY") or os.environ.get("OPENAI_API_KEY")
API_URL = os.environ.get("LLM_API_URL", "https://openrouter.ai/api/v1/chat/completions")
MODEL_NAME = os.environ.get("LLM_MODEL", "meta-llama/llama-3.3-70b-instruct")
DB_PATH = "agent_results.db"

def init_database():
    """Create local SQLite table to store subtask outputs."""
    with sqlite3.connect(DB_PATH) as conn:
        conn.execute("""
            CREATE TABLE IF NOT EXISTS subtask_results (
                id TEXT PRIMARY KEY,
                description TEXT,
                stdout TEXT,
                stderr TEXT,
                returncode INTEGER,
                completed_at TEXT
            )
        """)

def call_llm(prompt: str, system_prompt: str = "You are a senior algorithmic software engineer.") -> str:
    """Execute raw HTTP completion without third-party library dependencies."""
    if not API_KEY:
        raise ValueError("Please set OPENROUTER_API_KEY or OPENAI_API_KEY environment variable.")

    headers = {
        "Content-Type": "application/json",
        "Authorization": f"Bearer {API_KEY}",
        "User-Agent": "Berkeley-Agent-Workbench/2.0"
    }

    payload = {
        "model": MODEL_NAME,
        "messages": [
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": prompt}
        ],
        "temperature": 0.1
    }

    req = urllib.request.Request(API_URL, data=json.dumps(payload).encode("utf-8"), headers=headers)
    try:
        with urllib.request.urlopen(req, timeout=45) as resp:
            data = json.loads(resp.read().decode("utf-8"))
            return data["choices"][0]["message"]["content"].strip()
    except urllib.error.HTTPError as err:
        print(f"API HTTP Error {err.code}: {err.read().decode('utf-8')}", file=sys.stderr)
        raise

def generate_plan(objective: str) -> list:
    """Generate structured JSON array of actionable subtasks."""
    prompt = f"""Break down this engineering objective into 3 to 5 sequential Python coding subtasks:
Objective: {objective}

Output ONLY a JSON array. Each element must have:
- "id": "task_1", "task_2", etc.
- "description": Concrete technical description of Python code to write.
- "assertion": Plain-English check to verify success.

Format:
[
  {{"id": "task_1", "description": "...", "assertion": "..."}}
]"""
    raw = call_llm(prompt, system_prompt="Output valid JSON array only. Do not wrap in markdown fences.")
    # Clean potential markdown fences
    cleaned = raw.replace("```json", "").replace("```", "").strip()
    return json.loads(cleaned)

def execute_in_sandbox(python_code: str, timeout_sec: int = 30) -> dict:
    """Run generated code in an isolated subprocess with timeout constraints."""
    try:
        res = subprocess.run(
            [sys.executable, "-c", python_code],
            capture_output=True,
            text=True,
            timeout=timeout_sec
        )
        return {
            "stdout": res.stdout.strip(),
            "stderr": res.stderr.strip(),
            "returncode": res.returncode
        }
    except subprocess.TimeoutExpired:
        return {
            "stdout": "",
            "stderr": f"Execution timed out after {timeout_sec} seconds.",
            "returncode": 124
        }

def run_agent(objective: str):
    """Orchestrate planning, sandboxed execution, and SQLite state persistence."""
    init_database()
    print("=======================================================")
    print("🚀 BERKELEY AUTONOMOUS AGENT SANDBOX")
    print(f"• Objective: {objective}")
    print("=======================================================\n")

    print("🧠 Planning task breakdown...")
    tasks = generate_plan(objective)
    print(f"✓ Generated {len(tasks)} subtasks.\n")

    for task in tasks:
        task_id = task["id"]
        desc = task["description"]
        print(f"▶ Running [{task_id}]: {desc}")

        code_prompt = f"""Write a standalone Python script to accomplish this task:
{desc}

Rules:
1. Print final verified result to stdout.
2. Assert correctness of calculations.
3. Return only runnable Python code without markdown tags."""

        code = call_llm(code_prompt).replace("```python", "").replace("```", "").strip()
        result = execute_in_sandbox(code)

        status_str = "PASS ✅" if result["returncode"] == 0 else "FAIL ❌"
        print(f"  Result: [{status_str}] Return code: {result['returncode']}")
        if result["stdout"]:
            print(f"  Output: {result['stdout'][:120]}...")
        if result["stderr"]:
            print(f"  Error:  {result['stderr'][:120]}...")

        # Persist to SQLite
        with sqlite3.connect(DB_PATH) as conn:
            conn.execute(
                "INSERT OR REPLACE INTO subtask_results VALUES (?, ?, ?, ?, ?, ?)",
                (task_id, desc, result["stdout"], result["stderr"], result["returncode"], datetime.utcnow().isoformat())
            )
        print()

    print("=======================================================")
    print(f"🎉 Objective Complete! Results archived in '{DB_PATH}'.")
    print("=======================================================")

if __name__ == "__main__":
    test_objective = (
        sys.argv[1] if len(sys.argv) > 1 
        else "Calculate the first 25 Fibonacci numbers and verify Golden Ratio convergence."
    )
    run_agent(test_objective)
```

## 5. Security & Sandbox Hardening for Production

If you plan to run untrusted agent code on servers, harden the execution sandbox:

1. **Docker Isolation:** Wrap `execute_in_sandbox()` to invoke Docker with `--network none` and `--memory 512m` to prevent network exfiltration or memory hogging:
   ```bash
   docker run --rm --network none --memory 512m -v /tmp/code.py:/app/code.py python:3.11-slim python /app/code.py
   ```
2. **Read-Only Root Filesystems:** Mount host directories as read-only (`:ro`) to ensure the agent cannot overwrite existing code or system configurations.
3. **Structured Audit Logs:** Query `agent_results.db` to inspect historical code outputs and error rates across assignments:
   ```bash
   sqlite3 agent_results.db "SELECT id, returncode, completed_at FROM subtask_results;"
   ```

## 6. Key Takeaways from the Berkeley Experiment

1. **Chat Windows Encourage Passive Learning:** Typing questions into ChatGPT trains you to consume answers. Building autonomous task planners trains you to architect systems.
2. **SQLite Decouples Execution from Context Limits:** Storing subtask state in a local database eliminates context-window stuffing, dropping API costs by 95%.
3. **Execution Gating Is Non-Negotiable:** Never trust an AI model's code output until an actual Python interpreter runs it against concrete assertions.
