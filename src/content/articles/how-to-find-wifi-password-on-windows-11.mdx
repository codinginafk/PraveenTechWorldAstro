> **Quick direct answer:** To find your Wi-Fi password on Windows 11, press **Win + I** to open Settings. Go to **Network & internet** > **Wi-Fi** > **Manage known networks**, pick your network, and click **View** beside *View Wi-Fi security key*. To reveal passwords for any saved network while offline, open Terminal and run:
>
> ```powershell
> netsh wlan show profile name="YourNetworkName" key=clear
> ```

We have all been in this spot in the office. A colleague brings a new laptop or test bench phone to our lab desk. They ask for the guest Wi-Fi password. The router sits locked inside a server cabinet down the hall. Nobody wrote the key on a physical sticky note.

Fortunately, Windows 11 caches every single wireless profile you have ever joined. The operating system saves these pre-shared keys locally. 

Our team tested three separate recovery techniques on Windows 11 24H2 (build 26100). Below is the exact step-by-step runbook to extract your Wi-Fi credentials in seconds.

---

## 1. How to Find WiFi Password on Windows 11 in Settings

Windows 11 makes finding your active wireless credentials straightforward through the redesigned Settings menu. You do not need third-party utilities or risky key-scraping executables.

Follow these direct steps on your machine:

1. Press **Windows + I** on your keyboard to open the **Settings** application.
2. In the left navigation pane, select **Network & internet**.
3. Click on the **Wi-Fi** tile in the main panel.
4. Scroll down and click on **Manage known networks**.
5. Locate the Wi-Fi network you need from the list and click on it.
6. Look for the row labeled **View Wi-Fi security key**.
7. Click the **View** button on the right side of the row.
8. If prompted by User Account Control (UAC), click **Yes**. Your plaintext password appears immediately inside the dialog box.

```
[WINDOWS 11 SETTINGS WORKFLOW]

Win + I -> Network & internet -> Wi-Fi -> Manage known networks
                                              |
                                              v
                              Select SSID -> View Security Key
```

This graphical method is fast and clean. However, it has one major limitation. If your network connection is disabled or you are managing headless test hardware, navigating GUI sub-menus is inefficient. That is where the terminal method shines.

## 2. Reveal Any Saved Wi-Fi Password via Command Prompt or Terminal

The native Command Prompt method is our preferred tool on workbench PCs. It reveals security keys for **any network your computer has ever connected to**, even when your Wi-Fi card is switched off or disconnected.

Windows stores these credentials in encrypted XML files under the `C:\ProgramData\Microsoft\Wlansvc\Profiles\Interfaces\` directory. The built-in `netsh` utility decrypts them on demand.

### Step 1: Open Terminal as Administrator
Press **Win + X** and choose **Terminal (Admin)** or **Command Prompt (Admin)** from the menu.

### Step 2: List All Stored Wireless Profiles
Type the following command and hit **Enter**:

```cmd
netsh wlan show profiles
```

Windows prints an index of every wireless profile stored on your system:

```text
Profiles on interface Wi-Fi:

Group policy profiles (read only)
---------------------------------
    <None>

User profiles
-------------
    All User Profile     : Lab-Office-5G
    All User Profile     : Home-Fiber-Guest
    All User Profile     : Client-Site-Secure
```

### Step 3: Extract the Plaintext Password
Identify the exact name of the network you wish to view. Then execute the following command, replacing `Lab-Office-5G` with your actual network name:

```cmd
netsh wlan show profile name="Lab-Office-5G" key=clear
```

### Step 4: Locate the "Key Content" Field
Scroll down to the section titled **Security settings**. Look for the line named **Key Content**:

```text
Security settings
-----------------
    Authentication         : WPA2-Personal
    Cipher                 : CCMP
    Authentication         : WPA2-Personal
    Cipher                 : GCMP
    Security key           : Present
    Key Content            : MySuperSecretPass2026!
```

The string next to **Key Content** is your raw Wi-Fi password.

## 3. Bulk Export All Saved Wi-Fi Passwords with PowerShell

Querying networks one by one gets tedious when you manage multiple lab machines. When our team audits bench machines or migrates developers to new hardware, we use a single PowerShell command to extract all stored passwords into a clean table.

Open **PowerShell (Admin)** and paste the following snippet:

```powershell
(netsh wlan show profiles) | Select-String "\:(.+)$" | ForEach-Object {
    $name = $_.Matches.Groups[1].Value.Trim()
    $pass = (netsh wlan show profile name="$name" key=clear) | Select-String "Key Content\W+\:(.+)$"
    [PSCustomObject]@{
        NetworkName = $name
        Password    = if ($pass) { $pass.Matches.Groups[1].Value.Trim() } else { "[No PSK / Enterprise]" }
    }
} | Format-Table -AutoSize
```

### Script Output Preview:
```text
NetworkName        Password
-----------        --------
Lab-Office-5G      MySuperSecretPass2026!
Home-Fiber-Guest   WelcomeGuest2026#
Airport-Free-WiFi  [No PSK / Enterprise]
Corporate-RADIUS   [No PSK / Enterprise]
```

### Exporting to a Secure CSV
If you need to archive credentials for an office fleet migration, append `Export-Csv` to the command:

```powershell
(netsh wlan show profiles) | Select-String "\:(.+)$" | ForEach-Object {
    $name = $_.Matches.Groups[1].Value.Trim()
    $pass = (netsh wlan show profile name="$name" key=clear) | Select-String "Key Content\W+\:(.+)$"
    [PSCustomObject]@{
        SSID     = $name
        Password = if ($pass) { $pass.Matches.Groups[1].Value.Trim() } else { "None" }
    }
} | Export-Csv -Path "$HOME\Desktop\wifi-backup.csv" -NoTypeInformation
```

> **Security Alert:** Storing plain text Wi-Fi passwords in an unencrypted CSV file on your desktop creates security risks. Once you finish moving machines, delete the file and clear your recycle bin.

## 4. Why Is "Key Content" Blank? (Enterprise & 802.1X Gotchas)

Occasionally, you will run `netsh wlan show profile name="..." key=clear` and notice that the **Key Content** line is completely missing. 

This is not a bug in Windows 11. It happens because of how enterprise networks authenticate clients.

| Network Security Type | Authentication Mechanism | Can Windows Extract Password? |
| :--- | :--- | :--- |
| **WPA2 / WPA3 Personal** | Pre-Shared Key (PSK) | **Yes** (Stored in local profile XML) |
| **WPA2 / WPA3 Enterprise** | 802.1X / RADIUS Server | **No** (Uses user domain tokens or machine certs) |
| **Open / Captive Portal** | Browser Web Login | **No** (No pre-shared encryption key exists) |
| **WPA3-Personal SAE** | Simultaneous Authentication of Equals | **Yes** (Decrypted via Windows LSA) |

If you are connected to a university campus or corporate enterprise network, your device authenticates via **PEAP-MSCHAPv2** or **EAP-TLS certificates**. The router never gives your laptop a static pre-shared key. In those cases, you must authenticate using your personal Active Directory or Entra ID credentials.

## 5. Troubleshooting Common Wi-Fi Password Extraction Errors

During our testing across multiple Windows 11 builds, we ran into three common hiccups. Here is how our team solved them:

### Issue A: "Access is Denied" in Terminal
If Command Prompt outputs `Access is denied` when requesting `key=clear`, you launched the terminal under a standard user token. 
- **Fix:** Press **Win + S**, type `wt`, right-click **Terminal**, and select **Run as administrator**.

### Issue B: "The Wireless AutoConfig Service (wlansvc) Is Not Running"
If running `netsh wlan` produces an error stating the WLAN service is stopped, your wireless stack crashed or was disabled during a driver update.
- **Fix:** Open PowerShell as Admin and start the service manually:
  ```powershell
  Start-Service -Name WlanSvc
  ```

### Issue C: Network Names with Spaces or Special Characters
If your Wi-Fi name is `Dev Lab Guest 5GHz`, running `netsh wlan show profile name=Dev Lab Guest 5GHz key=clear` will throw a syntax error.
- **Fix:** Always wrap the network SSID in double quotes: `name="Dev Lab Guest 5GHz"`.

## 6. Summary Checklist for Windows 11 Wi-Fi Recovery

1. **For active home networks:** Use `Win + I` > `Network & internet` > `Wi-Fi` > `Manage known networks` > `View`.
2. **For offline or historical networks:** Use `netsh wlan show profile name="SSID" key=clear` in Command Prompt.
3. **For multiple machines:** Run our bulk PowerShell script to generate a formatted table.
4. **For corporate connections:** If Key Content is missing, contact your network administrator for 802.1X certificate provisioning.

By keeping these commands handy, you will never need to crawl behind an office desk or reboot a router to find a lost Wi-Fi password.
