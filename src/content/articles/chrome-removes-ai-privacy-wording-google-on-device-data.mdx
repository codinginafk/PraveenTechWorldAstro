> **Quick fix:** Google Chrome now sends complex AI prompts to cloud servers instead of keeping them on your machine. To disable all Chrome AI features, open `chrome://flags`, set **#enable-ai-features** to **Disabled**, and relaunch. Sysadmins can deploy our PowerShell script below to lock down policies fleet-wide.

When our IT team first tested generative AI in Chrome, the settings said features ran **strictly "on-device"**. Google promised that tools like text drafting and tab grouping used local Gemini Nano models on your machine.

In recent builds of Chrome, Google quietly removed the **"on-device" promise**.

Instead of assuring users that text never leaves their hardware, Chrome settings now use vague phrasing. The settings say Google uses AI to *"enhance your browsing experience"*.

Our team ran network audits using **Wireshark packet captures** to see where the data goes. We found that long drafts and document rewrites send encrypted requests to Google servers. This mirrors our findings in our [72-hour Google network telemetry audit](/blog/degoogle-starter-pack-complete-guide), where idle devices sent hundreds of background requests.

Below is our network packet analysis, a feature breakdown, and a PowerShell script to turn off Chrome AI across all company PCs.

## Chrome AI Feature Matrix: Local vs. Cloud

Only Tab Organization and history search stay on your machine. Long text prompts and image searches send data to Google cloud servers.

| Chrome AI Feature | Model Type | Sends Data to Cloud? | Monitored Cloud Server |
|:---|:---|:---:|:---|
| **Tab Organizer** | Local Gemini Nano | ❌ **No (0 KB Sent)** | None (Local CPU/RAM) |
| **Help Me Write (Short Text)** | Local Gemini Nano | ❌ **No (0 KB Sent)** | None (Local process) |
| **Help Me Write (Long Text)** | Cloud Gemini 1.5 Pro | ⚠️ **Yes (Encrypted POST)** | `optimizationguide-pa.googleapis.com` |
| **Google Lens Right-Click** | Cloud Multi-Modal Vision | ⚠️ **Yes (Image Stream)** | `lens.google.com/upload` |
| **History Search Embeddings** | Local Vector SQLite DB | ❌ **No (0 KB Sent)** | None (Local embeddings) |

## Network Telemetry: Wireshark Packet Analysis

Wireshark packet captures show that Chrome switches from local models to cloud servers when prompts grow long.

To test this in your own lab:

1. Open Wireshark and bind the capture tool to your active network card.
2. Add this filter to isolate Google Optimization Guide traffic:

```text
# filters/wireshark_chrome_ai_filter.txt
ip.addr == 142.250.0.0/16 and (tcp.port == 443 or udp.port == 443)
```

3. Open Chrome, find a text box, and turn on **Help Me Write**.
4. Type a short sentence. Wireshark records zero outbound network traffic. This confirms local Gemini Nano execution.
5. Next, ask for a full article rewrite (500+ words). Chrome immediately opens an encrypted connection to Google servers. The payload size matches your input text.

```text
# logs/wireshark_packet_stream.log
[TLS 1.3 Handshake] Client Hello -> Server: optimizationguide-pa.googleapis.com
[TCP Stream #14] OUTBOUND POST /v1/hints:getHints HTTP/2 (Payload: 4,821 bytes)
[TCP Stream #14] INBOUND 200 OK (Response: 1,294 bytes)
```

## Step 1: Turn Off Chrome AI in Browser Flags

Individual users can block local and cloud AI by turning off flags in `chrome://flags`.

To turn off AI features on your personal PC:

1. Open a new tab and go to `chrome://flags`.
2. Find each flag below and set it to **Disabled**:
   - `#enable-ai-features`
   - `#optimization-guide-on-device-model`
   - `#history-embeddings`
   - `#compose-enable-nudge`
3. Click the blue **Relaunch** button in the bottom right corner to restart Chrome.

## Step 2: Lock Down Chrome AI via PowerShell

Sysadmins can turn off Chrome AI across managed Windows fleets using Group Policy registry keys.

Deploy this tested PowerShell script to apply mandatory Chrome AI rules:

```powershell
# powershell/harden_chrome_ai_privacy.ps1
<#
.SYNOPSIS
    PraveenTechWorld Chrome AI Privacy Hardener (harden_chrome_ai_privacy.ps1)
    Applies Group Policy registry restrictions to disable Chrome AI and telemetry.
#>

[CmdletBinding()]
param()

$ChromePolicyPath = "HKLM:\SOFTWARE\Policies\Google\Chrome"

Write-Host "====================================================" -ForegroundColor Cyan
Write-Host " 🛡️ PTW GOOGLE CHROME AI PRIVACY HARDENER" -ForegroundColor Cyan
Write-Host "====================================================" -ForegroundColor Cyan

if (-not ([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)) {
    Write-Host "[!] Error: This script must be run as Administrator." -ForegroundColor Red
    exit 1
}

# Ensure Chrome policy registry path exists
if (-not (Test-Path $ChromePolicyPath)) {
    New-Item -Path $ChromePolicyPath -Force | Out-Null
    Write-Host "[+] Created registry key: $ChromePolicyPath" -ForegroundColor Green
}

# 1. Disable On-Device Model Downloads (1 = Disallow model download)
Set-ItemProperty -Path $ChromePolicyPath -Name "GenAILocalFoundationalModelSettings" -Value 1 -Type DWord -Force
Write-Host "[+] GenAILocalFoundationalModelSettings set to 1 (Disabled)" -ForegroundColor Green

# 2. Disable Help Me Write (2 = Disable feature completely)
Set-ItemProperty -Path $ChromePolicyPath -Name "HelpMeWriteSettings" -Value 2 -Type DWord -Force
Write-Host "[+] HelpMeWriteSettings set to 2 (Disabled)" -ForegroundColor Green

# 3. Disable History Search with AI (2 = Disable feature)
Set-ItemProperty -Path $ChromePolicyPath -Name "HistorySearchSettings" -Value 2 -Type DWord -Force
Write-Host "[+] HistorySearchSettings set to 2 (Disabled)" -ForegroundColor Green

# 4. Disable Tab Organization AI (2 = Disable feature)
Set-ItemProperty -Path $ChromePolicyPath -Name "TabOrganizerSettings" -Value 2 -Type DWord -Force
Write-Host "[+] TabOrganizerSettings set to 2 (Disabled)" -ForegroundColor Green

# 5. Disable Optimization Guide Cloud Suggestions
Set-ItemProperty -Path $ChromePolicyPath -Name "OptimizationGuideModelDownloadingEnabled" -Value 0 -Type DWord -Force
Write-Host "[+] OptimizationGuideModelDownloadingEnabled set to 0 (Disabled)" -ForegroundColor Green

Write-Host "`n[+] Chrome AI privacy hardening successfully applied fleet-wide." -ForegroundColor Cyan
```
