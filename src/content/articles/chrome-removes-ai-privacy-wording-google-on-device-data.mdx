When Google first introduced generative AI into the Chrome browser, the settings panel explicitly highlighted that features like tab organization, text drafting, and history search operated **"on-device"** using local Gemini Nano weights.

In recent stable builds of Chrome, that explicit **"on-device" guarantee was quietly removed**.

Instead of reassuring users that private drafts never leave their hardware, Chrome settings now display generic language about *"using AI to enhance your browsing experience"*.

On our IT workbench, our team wanted hard technical evidence rather than PR statements. We configured **Wireshark packet captures** and Chrome internal debugging tools (`chrome://net-export`) to audit whether Chrome transmits your private text to Google cloud servers.

Here is what we discovered and how to disable Chrome AI telemetry entirely.

---

## 📊 Chrome AI Feature Matrix: Local Edge vs. Cloud Transmission

| Chrome AI Feature | Model Architecture | Transmits Text to Cloud? | Network Endpoint Detected |
|:---|:---|:---:|:---|
| **Tab Organizer** | Local Gemini Nano (On-Device) | ❌ **No (0 KB Sent)** | None (Local process memory) |
| **Help Me Write (Short Prompt)** | Local Gemini Nano | ❌ **No (0 KB Sent)** | None |

| **Smart History Search** | Local Vector Embeddings | ❌ **No (Local Vector DB)** | None |

## ⚡ How We Audited Chrome AI Packets with Wireshark

To verify whether your text leaves your computer when interacting with browser AI:

1. Launch Wireshark and bind the packet sniffer to your active network interface (Ethernet or Wi-Fi).
2. Set the display capture filter to Google's Optimization Guide service:

```wireshark
ip.addr == 142.250.0.0/16 and ssl.handshake
```

3. Type a paragraph into a web form and trigger **Help Me Write**.
4. If the prompt is handled by **Gemini Nano**, Wireshark displays zero outbound TCP streams.
5. If the prompt exceeds local token limits, Chrome initiates an outbound TLS handshake with `optimizationguide-pa.googleapis.com`.

## 🔒 Step-by-Step: How to Permanently Disable Chrome AI

### Option A: Disable via Chrome Flags (Individual Users)
1. Open a new tab and navigate to `chrome://flags`.
2. In the search box, search for `Optimization Guide`.
3. Set the following flags to **Disabled**:
   - `#enable-ai-features`
   - `#optimization-guide-on-device-model`
   - `#history-embeddings`
4. Click **Relaunch** at the bottom right.

---

### Option B: Group Policy GPO Disable (Enterprise Sysadmins)

To block AI data leakage across company workstations:

```powershell
# Disable Google Chrome AI features via PowerShell Registry (Admin)
$Path = "HKLM:\SOFTWARE\Policies\Google\Chrome"
If (!(Test-Path $Path)) { New-Item -Path $Path -Force }
Set-ItemProperty -Path $Path -Name "GenAILocalFoundationalModelSettings" -Value 1 -Type DWord
Set-ItemProperty -Path $Path -Name "HelpMeWriteSettings" -Value 2 -Type DWord
```
