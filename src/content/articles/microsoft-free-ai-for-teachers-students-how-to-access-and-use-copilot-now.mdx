## 3. Step-by-Step Access Runbook: Activating Free Copilot

**Follow this 4-step sequence to verify and activate institutional Copilot on your school workstation:**

### Step 1: Verify Institutional Account Eligibility
- Your institution must hold a valid **Microsoft 365 Education (A1, A3, or A5)** agreement.
- Standard `.edu` emails, regional school district addresses (e.g., `@schools.nyc.gov`), and university accounts qualify.

### Step 2: Access the Dedicated Education Portal
- Open a modern web browser and navigate directly to **`copilot.microsoft.com`** or **`microsoft365.com/copilot`**.
- *Important:* Avoid logging in through standard personal consumer Bing pages, which default to consumer terms of service.

### Step 3: Sign In via Single Sign-On (SSO)
- Click the **Sign In** button located in the upper right-hand corner.
- Select **Sign in with a work or school account**.
- Complete your school's standard multi-factor authentication (MFA) challenge.

### Step 4: Validate the Commercial Data Protection Shield
- Inspect your user badge in the upper right-hand corner.
- Confirm the presence of the green **Protected** shield icon with the message: *"Your personal and company data are protected in this chat."*
- If the shield is absent, your district IT administrator has not enabled the Copilot service plan in the Microsoft 365 admin center.

## 5. IT Administrator PowerShell Script: Verify Tenant License Eligibility

**School district system administrators can run this native PowerShell script to verify that student and faculty users have Commercial Data Protection properly assigned:**

```powershell
# Audit-M365EducationCopilot.ps1
# Requires: Install-Module Microsoft.Graph -Scope CurrentUser
# Verifies Copilot service plan enablement across Microsoft 365 Education tenants

Import-Module Microsoft.Graph.Users
Import-Module Microsoft.Graph.Identity.DirectoryManagement

Connect-MgGraph -Scopes "User.Read.All", "Directory.Read.All"

Write-Host "[*] Auditing Microsoft 365 Education Tenant for Copilot Protection..." -ForegroundColor Cyan

# Service Plan ID for Commercial Data Protection
$CDP_SERVICE_PLAN = "Bing_Chat_Enterprise"

$educationUsers = Get-MgUser -Filter "assignedLicenses/any()" -All -Property DisplayName, UserPrincipalName, AssignedLicenses, AssignedPlans

$report = foreach ($user in $educationUsers) {
    $hasCopilotEnabled = $user.AssignedPlans | Where-Object { 
        $_.Service -like "*Bing*" -or $_.Service -like "*Copilot*" -and $_.CapabilityStatus -eq "Enabled" 
    }
    
    [PSCustomObject]@{
        DisplayName        = $user.DisplayName
        UserPrincipalName  = $user.UserPrincipalName
        CopilotStatus      = if ($hasCopilotEnabled) { "Protected (Active)" } else { "Unlicensed / Disabled" }
    }
}

$report | Format-Table -AutoSize
$activeCount = ($report | Where-Object { $_.CopilotStatus -like "*Active*" }).Count
Write-Host "[SUCCESS ✅] Total Protected Education Users: $activeCount / $($report.Count)" -ForegroundColor Green
```

## 6. Python Grade Analysis & Rubric Parser Script

**Educators can use this lightweight Python script on their local workstation to categorize student quiz errors into targeted review clusters without exposing student names to cloud services:**

```python
#!/usr/bin/env python3
"""
scripts/copilot_rubric_generator.py
Anonymizes and categorizes student quiz scores to identify classroom learning gaps.
Requires: pip install pandas
"""

import pandas as pd
import json

# Sample quiz score data (Question ID: Percentage Correct)
QUIZ_RESULTS = {
    "Q1_Cell_Membrane": 92.5,
    "Q2_Osmosis_Diffusion": 58.0,
    "Q3_Active_Transport": 62.5,
    "Q4_Mitochondria_ATP": 88.0,
    "Q5_Photosynthesis_Calvin": 44.0
}

def analyze_concept_mastery(scores):
    remediation_needed = []
    mastered = []
    
    for question, score in scores.items():
        if score < 70.0:
            remediation_needed.append({"concept": question.replace("_", " "), "score_pct": score})
        else:
            mastered.append({"concept": question.replace("_", " "), "score_pct": score})
            
    return {
        "mastered_concepts": mastered,
        "remediation_priority": sorted(remediation_needed, key=lambda x: x["score_pct"])
    }

if __name__ == "__main__":
    print("[*] Analyzing Anonymized Classroom Mastery Data...")
    analysis = analyze_concept_mastery(QUIZ_RESULTS)
    
    print("\n[!] CRITICAL CONCEPTS REQUIRING RETEACHING:")
    for item in analysis["remediation_priority"]:
        print(f"  - {item['concept']}: {item['score_pct']}% passing")
        
    print("\n[*] GENERATING COPILOT INTERVENTION PROMPT:")
    prompt = (
        f"Act as a high school biology curriculum specialist. My students struggled on these concepts: "
        f"{[i['concept'] for i in analysis['remediation_priority']]}. "
        f"Design a 20-minute small-group review activity with hands-on manipulatives to address these specific gaps."
    )
    print(f'"{prompt}"')
```

## 7. Institutional FERPA & Student Privacy Compliance Checklist

**School administrators and teachers must enforce these 4 operational guardrails:**

1. **Verify the Green Shield Always:** If a student or teacher uses Copilot without the green shield, the session is falling back to consumer Bing, which logs IP addresses and search queries.
2. **Never Input Direct Student PII:** Even with Commercial Data Protection, never type full student legal names, medical records, or home addresses into prompt windows. Use generic pseudonyms (*"Student A"*, *"Student B"*).
3. **Audit Third-Party Add-Ins:** Disable unvetted third-party Copilot plugins in the Microsoft Admin Center to prevent third-party vendors from accessing prompt context.
4. **Establish Clear AI Syllabus Guidelines:** Transition classroom policy from outright bans to transparent attribution, requiring students to submit prompt transcripts when AI is permitted.
