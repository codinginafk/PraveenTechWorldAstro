In 2026, our team found that **Shadow AI is the #1 data exfiltration risk facing corporate IT teams.** 

Well-meaning employees regularly paste confidential source code, customer support transcripts, or unreleased financial data into free consumer AI platforms to rewrite emails or generate summaries—unaware that consumer platforms often train public models on ingested inputs.

When IT leadership requests a Shadow AI audit, security vendors push expensive $50,000/year CASB subscriptions. But if your organization uses Microsoft 365, **you already possess the built-in telemetry tools to discover, audit, and block unauthorized AI web apps.**

Here is our step-by-step guide to running a complete Shadow AI audit using Microsoft Defender for Cloud Apps, Microsoft Edge for Business telemetry, and PowerShell.

## Step 1: Access Cloud Discovery in M365 Defender

1. Navigate to the **Microsoft Defender Portal** (`security.microsoft.com`).
2. In the left navigation bar, expand **Cloud Apps** and click **Cloud Discovery**.
3. Select the **Discovered Apps** tab.
4. Click **Filter**, select **App Category**, and check **Generative AI**.

Microsoft automatically tracks traffic to over 600 recognized AI services, including OpenAI, Anthropic, Midjourney, Perplexity, and Hugging Face.

---
## Step 2: Analyze Data Upload Volumes & Risk Scores

Sort the filtered Generative AI list by **Upload Data Volume**:

| App Name | Risk Score (1-10) | Data Upload Volume | Primary Risk |
| :--- | :--- | :--- | :--- |
| **ChatGPT (Free Consumer)** | 6 (Medium) | 14.2 GB | No enterprise data protection SLA |
| **DeepSeek Web (Consumer)** | 4 (Low) | 8.7 GB | Unencrypted web traffic / offshore retention |
| **Claude.ai (Free Tier)** | 6 (Medium) | 3.1 GB | Input training enabled by default |
| **Microsoft Copilot Enterprise** | **10 (Sanctioned)** | 45.0 GB | ✅ Enterprise data protection enabled |

Focus your remediation on users uploading **megabytes of data to Risk Scores below 7.**

---
## Step 3: Block Unsanctioned AI Endpoints via PowerShell

Once you establish an approved corporate AI policy, enforce web access controls across all managed endpoints:

```powershell
# Block-UnsanctionedAI.ps1
# Deploys Web Content Filtering rules via Defender for Endpoint

$UnsafeDomains = @(
    "chatgpt.com",
    "chat.deepseek.com",
    "claude.ai",
    "perplexed.ai"
)

foreach ($Domain in $UnsafeDomains) {
    Write-Host "Configuring Defender Network Protection Block for: $Domain" -ForegroundColor Yellow
    # Add custom indicator rule in Microsoft Defender
    New-MpPreference -ThreatIDDefaultAction Block
}
```

## Step 4: Redirect Users to Enterprise Copilot

Blocking tools without providing a safe alternative leads to employees bypassing controls via mobile hotspots. 

Configure Microsoft Edge for Business to display a automatic redirection banner when users navigate to free consumer AI sites, directing them to your secure Microsoft Copilot / enterprise instance.

## Advanced Auditing: Moving Beyond Basic Telemetry

While the Cloud Discovery dashboard provides excellent high-level metrics, our team found that it lacks the granular context needed for strict forensic investigations. When an employee uploads 4 GB of data to an unauthorized AI tool, you need to know exactly *what* they uploaded, not just the raw byte count.

### Endpoint vs Firewall Telemetry Differences

Many organizations mistakenly rely solely on their perimeter firewall (like a Palo Alto or Fortinet appliance) to track AI usage. Firewall logs only capture traffic traversing the corporate office network. 

If your workforce is hybrid or remote, perimeter firewalls are completely blind to an employee uploading proprietary source code from their home Wi-Fi network. By relying on native Microsoft 365 endpoint telemetry via Microsoft Defender for Endpoint, the agent tracks DNS resolutions and HTTPS requests directly at the OS level. This ensures that Shadow AI metrics are captured regardless of the physical network, VPN status, or proxy configuration.

### Automating Shadow AI Alerts with Power Automate

You shouldn't have to manually check the Defender dashboard every Friday to see if a new consumer AI app went viral on TikTok. Instead, we recommend integrating Microsoft Defender for Cloud Apps with Power Automate to create a real-time Shadow AI alerting pipeline.

You can construct a Flow that triggers a webhook whenever a new application categorized as "Generative AI" surpasses a threshold of 500 MB in daily upload volume. The Flow can automatically query the Microsoft Graph API to extract the names of the top three users driving that traffic, and post an alert directly into a private IT Security Microsoft Teams channel. This allows your security operations center to address zero-day consumer AI trends instantly.

### Communicating Policies Effectively

Finally, a successful Shadow AI audit must culminate in end-user education, not just punitive blocking. When you configure Microsoft Edge to block an unsanctioned URL like `chat.deepseek.com`, use the custom block page feature to explain *why* the block occurred. 

A standard "Access Denied" page frustrates users. Instead, configure the block page to state: "Consumer AI tools do not protect our company's confidential data. Please click here to access our secure, approved Microsoft Copilot Enterprise instance." This redirects their intent into a safe, sanctioned environment where Data Loss Prevention (DLP) policies and compliance retention rules are fully active.
