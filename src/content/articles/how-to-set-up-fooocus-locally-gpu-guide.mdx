## 4. Step-by-Step Installation Runbook for Windows 11

### Step 1: Download the Fooocus Entry Package
Avoid cloning the raw Git repository unless you plan to develop core codebase extensions. The official entry package contains a pre-compiled, self-contained Python virtual environment with all required PyTorch and CUDA binaries:
1. Navigate to the official [Fooocus GitHub Repository](https://github.com/lllyasviel/Fooocus).
2. Download the **Fooocus Entry Package** 7z archive (~1.8GB).

### Step 2: Extract to an SSD Root Directory
Do **not** extract Fooocus into your `C:\Program Files` or `C:\Users\Username\Desktop` folders, as Windows UAC permission constraints frequently block Python background execution:
1. Create a root directory on your fastest NVMe/SATA SSD: `C:\Fooocus` or `D:\Fooocus`.
2. Use 7-Zip or WinRAR to extract the archive contents directly into this directory.

### Step 3: Initial Initialization and Model Weight Ingestion
1. Open your `C:\Fooocus` directory in Windows Explorer.
2. Double-click **`run.bat`** (or `run_anime.bat` for illustration styling).
3. The command prompt window will automatically fetch the default base checkpoint (`juggernautXL_v8.safetensors`, 6.6GB) and default LoRA modules.
4. Once completed, your default browser will launch `http://127.0.0.1:7865`.

## 5. Automated PowerShell Hardware Detection & Launcher Script

**Run our team's native PowerShell startup script to automatically detect your physical GPU VRAM and inject the optimal performance flags:**

```powershell
# Start-Fooocus.ps1
# Automates VRAM detection and optimal flag injection for Fooocus
# Location: C:\Fooocus\Start-Fooocus.ps1

$ErrorActionPreference = "Stop"
Write-Host "[*] Initializing PraveenTechWorld Fooocus Hardware Evaluator..." -ForegroundColor Cyan

# Step 1: Query Physical GPU Adapter Memory via WMI
$gpu = Get-CimInstance Win32_VideoController | Where-Object { $_.Name -like "*NVIDIA*" } | Select-Object -First 1

if (-not $gpu) {
    Write-Host "[!] No dedicated NVIDIA GPU detected! Searching for AMD DirectML..." -ForegroundColor Yellow
    $launchTarget = "run_directml.bat"
} else {
    $vramGB = [math]::Round($gpu.AdapterRAM / 1GB, 1)
    Write-Host "[+] Detected GPU: $($gpu.Name) with $vramGB GB VRAM" -ForegroundColor Green
    
    if ($vramGB -lt 6.0) {
        Write-Host "[!] Low VRAM detected (<6GB). Injecting --lowvram flag." -ForegroundColor Yellow
        $launchArgs = "--lowvram"
    } elseif ($vramGB -ge 12.0) {
        Write-Host "[+] High VRAM detected (>=12GB). Injecting --always-high-vram." -ForegroundColor Green
        $launchArgs = "--always-high-vram"
    } else {
        $launchArgs = ""
    }
    $launchTarget = "run.bat"
}

# Step 2: Launch Fooocus with determined arguments
$fooocusDir = Split-Path -Parent $MyInvocation.MyCommand.Path
Set-Location $fooocusDir

Write-Host "[*] Launching: $launchTarget $launchArgs" -ForegroundColor Cyan
Start-Process -FilePath "cmd.exe" -ArgumentList "/c $launchTarget $launchArgs"
```

## 7. Troubleshooting Top 3 Fooocus CUDA Errors

1. **CUDA Out of Memory (OOM) During Image Generation:**
   - *Cause:* Running large batches or 1024x1024 resolutions exceeding GPU buffer.
   - *Fix:* Edit `run.bat` to add `--lowvram` or `--always-offload-from-vram`. Lower resolution to 896x1152 in the UI.
2. **Port Collision: `Port 7865 is already in use`:**
   - *Cause:* A zombie Python process from a prior session is still bound to the port.
   - *Fix:* Open PowerShell and run: `Get-Process python | Stop-Process -Force`, or launch with `run.bat --port 7866`.
3. **Slow First-Generation Freeze (10+ Minutes):**
   - *Cause:* Normal behavior during initial model ingestion while PyTorch compiles CUDA kernels and caches weights to disk.
   - *Fix:* Ensure Fooocus resides on an NVMe SSD rather than an external mechanical HDD.
