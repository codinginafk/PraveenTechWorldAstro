> **Direct Answer (How to Uninstall Windows 11 AI Components):** To permanently uninstall and block Microsoft AI components (Copilot, Recall, and background NPU daemons) from Windows 11: (1) disable the Recall OS package using DISM (`dism /Online /Disable-Feature /FeatureName:Recall /NoRestart`), (2) purge Copilot AppX packages across all user profiles using `Get-AppxPackage -AllUsers *Microsoft.Copilot* | Remove-AppxPackage -AllUsers`, (3) enforce Group Policy / Registry locks under `HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsCopilot` (`TurnOffWindowsCopilot = 1`) and `WindowsRecall` (`DisableRecall = 1`) to block update reinstallation, and (4) restart your workstation to free up to 11.8GB of disk space and 450MB of idle RAM.

When our engineering and IT operations team provisioned our latest fleet of Windows 11 workstations (including Snapdragon X Elite and Intel Core Ultra Copilot+ PCs), Task Manager revealed multiple persistent background daemons: `Copilot.exe`, `RecallSnapshotHost.exe`, and continuous neural processing co-processor polling loops.

## 🛠️ Method 1: Uninstall AI Components via Windows 11 Settings GUI

**Direct Answer:** Use the modular AI Components interface under *Settings > System > AI Components* to uninstall Copilot, Recall, and Live Captions models with standard user privileges.

In the latest Windows 11 builds, Microsoft grouped generative components into a modular settings panel:

1. Press `Win + I` to open **Settings**.
2. Navigate to **System > AI Components** (or **Apps > Installed Apps**).
3. Under the **System AI Features** section, locate the target modules:
   - **Microsoft Copilot**
   - **Windows Recall**
   - **Click to Do / AI Actions**
   - **Live Captions AI Model**
4. Click the three horizontal dots `...` next to each component and select **Uninstall**.
5. Restart your workstation to allow the servicing stack to unbind the packages.

## 🛠️ Method 2: Purge Windows Recall & Copilot via PowerShell & DISM

**Direct Answer:** Run elevated DISM and AppX PowerShell commands to remove the underlying OS feature binaries and prevent stub daemons from remaining active.

For clean IT deployments and power users, GUI toggles often leave background service stubs intact. Use elevated **PowerShell** to permanently unregister the packages:

### 1. Disable the Windows Recall OS Feature
Open PowerShell as Administrator and execute:

```powershell
# powershell/disable_recall_dism.ps1
# Disable Windows Recall snapshot engine in the active OS servicing image
dism.exe /Online /Disable-Feature /FeatureName:Recall /NoRestart
```

### 2. Purge Copilot AppX Packages Across All User Profiles
Execute this pipeline to remove Copilot applications and provisioned packages:

```powershell
# powershell/remove_copilot_appx.ps1
# 1. Remove provisioned Copilot package from new user account templates
Get-AppxProvisionedPackage -Online | Where-Object { $_.DisplayName -match "Copilot" } | Remove-AppxProvisionedPackage -Online

# 2. Remove Copilot application from all existing local user profiles
Get-AppxPackage -AllUsers *Microsoft.Copilot* | Remove-AppxPackage -AllUsers
Get-AppxPackage -AllUsers *Microsoft.Windows.Ai.Copilot* | Remove-AppxPackage -AllUsers
```

## 🛠️ Method 3: Group Policy & Registry Lockdown (Block Reinstallation)

**Direct Answer:** Configure Group Policy or Registry keys under `HKLM\SOFTWARE\Policies\Microsoft\Windows` to prevent Windows Update from automatically re-provisioning AI components during cumulative updates.

Whenever Windows installs cumulative monthly updates, it checks for missing default packages. To prevent Windows Update from reinstalling AI components, enforce system-wide policy locks:

### 1. Group Policy Editor (Windows 11 Pro / Enterprise):
1. Press `Win + R`, type `gpedit.msc`, and press Enter.
2. Navigate to: `Computer Configuration > Administrative Templates > Windows Components > Windows Copilot`.
3. Double-click **Turn off Windows Copilot** and set it to **Enabled**.
4. Navigate to: `Computer Configuration > Administrative Templates > Windows Components > Windows Recall`.
5. Double-click **Turn off saving snapshots for Windows** and set it to **Enabled**.

### 2. Registry Hardening (All Windows 11 Editions including Home):

Run these commands in an elevated PowerShell terminal:

```powershell
# powershell/harden_registry_ai.ps1
# 1. Disable Windows Copilot system-wide
New-Item -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\WindowsCopilot" -Force | Out-Null
Set-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\WindowsCopilot" -Name "TurnOffWindowsCopilot" -Value 1 -Type DWord

# 2. Disable Windows Recall snapshot collection
New-Item -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\WindowsRecall" -Force | Out-Null
Set-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\WindowsRecall" -Name "DisableRecall" -Value 1 -Type DWord

# 3. Disable Windows generative search telemetry
New-Item -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\Windows Search" -Force | Out-Null
Set-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\Windows Search" -Name "AllowCloudSearch" -Value 0 -Type DWord
```

## ⚡ Automated Script: Complete Windows AI Purge Runbook

**Direct Answer:** Deploy this all-in-one PowerShell automation script to disable Recall, purge Copilot AppX packages, and apply registry locks in a single automated step.

Save and execute this script with Administrator privileges:

```powershell
# powershell/purge_windows_ai_components.ps1
# PraveenTechWorld Windows 11 AI Component Cleanup Runbook
# Requires: Run as Administrator

Write-Host "====================================================" -ForegroundColor Cyan
Write-Host " 🛡️ WINDOWS 11 AI COMPONENT PURGE & HARDENING" -ForegroundColor Cyan
Write-Host "====================================================" -ForegroundColor Cyan

# 1. Disable DISM Recall Feature
Write-Host "[*] Disabling Windows Recall feature via DISM..." -ForegroundColor Yellow
dism.exe /Online /Disable-Feature /FeatureName:Recall /NoRestart

# 2. Remove Copilot AppX Packages
Write-Host "[*] Purging Copilot packages for all user profiles..." -ForegroundColor Yellow
Get-AppxPackage -AllUsers *Microsoft.Copilot* | Remove-AppxPackage -AllUsers -ErrorAction SilentlyContinue
Get-AppxPackage -AllUsers *Microsoft.Windows.Ai.Copilot* | Remove-AppxPackage -AllUsers -ErrorAction SilentlyContinue
Get-AppxProvisionedPackage -Online | Where-Object { $_.DisplayName -match "Copilot" } | Remove-AppxProvisionedPackage -Online -ErrorAction SilentlyContinue

# 3. Apply Registry Policy Lockdown
Write-Host "[*] Writing GPO registry security keys..." -ForegroundColor Yellow
$CopilotPath = "HKLM:\SOFTWARE\Policies\Microsoft\Windows\WindowsCopilot"
$RecallPath = "HKLM:\SOFTWARE\Policies\Microsoft\Windows\WindowsRecall"

if (!(Test-Path $CopilotPath)) { New-Item -Path $CopilotPath -Force | Out-Null }
Set-ItemProperty -Path $CopilotPath -Name "TurnOffWindowsCopilot" -Value 1 -Type DWord

if (!(Test-Path $RecallPath)) { New-Item -Path $RecallPath -Force | Out-Null }
Set-ItemProperty -Path $RecallPath -Name "DisableRecall" -Value 1 -Type DWord

Write-Host "[+] AI Components purged and locked successfully!" -ForegroundColor Green
Write-Host "[!] Please restart your computer to finalize changes." -ForegroundColor Cyan
Write-Host "====================================================" -ForegroundColor Cyan
```

## 📋 Verification: Checking Task Manager & NPU Telemetry

**Direct Answer:** Inspect Task Manager's Details and Performance tabs to verify that `Copilot.exe` and `RecallSnapshotHost.exe` are absent and NPU idle load sits at 0%.

After restarting your computer, verify cleanup success:

```powershell
# powershell/verify_ai_cleanup.ps1
# Verify AI processes are not running
$aiProcesses = Get-Process -Name "*Copilot*", "*Recall*" -ErrorAction SilentlyContinue
if ($null -eq $aiProcesses) {
    Write-Host "[PASS] No Copilot or Recall processes active in memory." -ForegroundColor Green
} else {
    Write-Host "[FAIL] AI processes detected: $($aiProcesses.Name -join ', ')" -ForegroundColor Red
}
```

1. Press `Ctrl + Shift + Esc` to open **Task Manager**.
2. Click the **Performance** tab and select **NPU (Neural Processing Unit)**.
3. At idle, NPU utilization will display **0.0%**, with 0 background disk write spikes from screenshot capture hosts.
