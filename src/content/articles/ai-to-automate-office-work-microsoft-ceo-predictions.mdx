## 4. Tenant Security: Auditing SharePoint Permissions with PowerShell

**The biggest risk when rolling out Copilot is data oversharing. If your company left sensitive salary files or executive notes accessible to 'All Employees', Copilot will summarize them for anyone who asks.**

Run this native PowerShell script to scan SharePoint online sites for broad public access before enabling Copilot licenses:

```powershell
# Audit-M365CopilotPermissions.ps1
# Requires PnP.PowerShell module: Install-Module PnP.PowerShell
param (
    [Parameter(Mandatory=$true)]
    [string]$TenantAdminUrl
)

Write-Host "[*] Connecting to SharePoint Tenant Admin: $TenantAdminUrl" -ForegroundColor Cyan
Connect-PnPOnline -Url $TenantAdminUrl -Interactive

$Sites = Get-PnPTenantSite -Filter "Url -like '*'"

Write-Host "`n=== AUDITING SHAREPOINT SITES FOR OVERSHARING RISKS ===" -ForegroundColor Yellow

foreach ($Site in $Sites) {
    try {
        Connect-PnPOnline -Url $Site.Url -Interactive
        $Web = Get-PnPWeb -Includes HasUniqueRoleAssignments
        
        # Check if site is set to public or allows broad organization-wide sharing
        if ($Site.SharingCapability -match "ExternalUserAndGuestSharing|ExternalUserSharingOnly") {
            Write-Host "[RISK ⚠️] Broad Sharing Enabled on: $($Site.Url)" -ForegroundColor Magenta
        } else {
            Write-Host "[PASS ✅] Restricted Sharing on: $($Site.Url)" -ForegroundColor Green
        }
    } catch {
        Write-Host "[WARN ⚪] Could not inspect site: $($Site.Url) - $($_.Exception.Message)" -ForegroundColor Gray
    }
}

Write-Host "`n[*] Tenant permission audit complete. Lock down broad folders before Copilot indexing." -ForegroundColor Cyan
```

## 5. Python Automation: Batch Processing Office Documents with Zero Retention

**For teams requiring bulk document summarization without manual Word interaction, use this standalone Python script connected to enterprise Azure OpenAI endpoints:**

```python
#!/usr/bin/env python3
"""
scripts/copilot_document_batcher.py
Batch summarizes Word/Text executive memos using Azure OpenAI Enterprise API.
Enforces zero-data retention headers and outputs clean Markdown summaries.
"""

import os
import sys
import json
import urllib.request
import urllib.error

ENDPOINT = os.getenv("AZURE_OPENAI_ENDPOINT", "https://your-resource.openai.azure.com")
API_KEY = os.getenv("AZURE_OPENAI_KEY", "your-api-key")
DEPLOYMENT = os.getenv("AZURE_OPENAI_DEPLOYMENT", "gpt-4o")
API_VERSION = "2024-08-01-preview"

def summarize_document(file_path: str) -> str:
    with open(file_path, 'r', encoding='utf-8', errors='ignore') as f:
        content = f.read()[:8000] # Cap context window for fast batching

    url = f"{ENDPOINT}/openai/deployments/{DEPLOYMENT}/chat/completions?api-version={API_VERSION}"
    
    headers = {
        "Content-Type": "application/json",
        "api-key": API_KEY,
        "x-ms-client-request-id": "ptw-copilot-batcher-01"
    }
    
    payload = {
        "messages": [
            {
                "role": "system", 
                "content": "You are an executive assistant. Summarize this document into: 1) Executive Summary, 2) Key Decisions, 3) Immediate Action Items with Owners."
            },
            {"role": "user", "content": content}
        ],
        "temperature": 0.2,
        "max_tokens": 800
    }
    
    req = urllib.request.Request(url, data=json.dumps(payload).encode('utf-8'), headers=headers)
    
    try:
        with urllib.request.urlopen(req) as response:
            result = json.loads(response.read().decode('utf-8'))
            return result['choices'][0]['message']['content']
    except urllib.error.HTTPError as e:
        return f"[ERROR] API Request Failed: {e.code} - {e.read().decode('utf-8')}"

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("Usage: python copilot_document_batcher.py <path-to-document.txt>")
        sys.exit(1)
        
    doc_path = sys.argv[1]
    print(f"[*] Processing document: {doc_path}...")
    summary = summarize_document(doc_path)
    print("\n" + "="*50)
    print(" EXECUTIVE COPILOT SUMMARY")
    print("="*50)
    print(summary)
    print("="*50 + "\n")
```

## 6. The Production Enterprise Prompt Library

**Vague prompts generate generic corporate fluff. Our workbench tested and verified these 3 high-performance enterprise prompts:**

### 1. Excel Financial Modeling Prompt
```text
Role: Senior Financial Analyst.
Task: Analyze the attached Q3 revenue dataset.
Instructions:
1. Calculate the compound monthly growth rate (CMGR) across all 4 product tiers.
2. Flag any product category where churn exceeded 4.5% in any single month.
3. Generate the exact Excel formula to calculate net dollar retention (NDR) in cell G42.
4. Output the results in a 3-column markdown table without introductory conversational filler.
```

### 2. Teams Meeting Action-Item Extractor Prompt
```text
Role: Technical Project Lead.
Task: Parse this 45-minute sprint retrospective transcript.
Instructions:
1. Extract every explicit commitment made by team members using the format: [Owner] - [Action Item] - [Deadline].
2. Identify any unresolved technical blockers and tag the designated escalation contact.
3. Ignore casual conversational banter and side discussions.
```

### 3. Executive Briefing Redaction Prompt
```text
Role: Corporate Communications Specialist.
Task: Convert this 12-page technical architecture proposal into a 1-page C-suite memo.
Instructions:
1. Limit output to exactly 3 sections: Strategic Objective, Projected Infrastructure Cost Savings, and 90-Day Implementation Risks.
2. Replace all technical networking jargon with business-impact metrics.
3. Highlight any required capital expenditures in bold text.
```

## Decision Summary: How to Lead the 18-Month Transition

- **Start with task audits, not tool rollouts:** Map your weekly workload into rules-based, analytical, and relational buckets before purchasing software licenses.
- **Audit your SharePoint permissions immediately:** Prevent corporate data leaks by revoking broad public sharing links before enabling search indexers.
- **Enforce human verification gates:** Never forward AI-generated financial models, contract redlines, or executive summaries without human review.
