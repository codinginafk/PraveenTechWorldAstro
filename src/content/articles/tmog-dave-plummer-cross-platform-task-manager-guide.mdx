Dave Plummer, the engineer who wrote the original Windows NT Task Manager, released TMOG as a native cross-platform system monitor. TMOG runs on Windows 11, macOS 14+, and Linux using a shared C++20 core without Electron bloat. The base monitor is free, while a $39.95 Pro license unlocks Flight Recorder telemetry.

Thirty years after slipping Task Manager into Windows NT 4.0, Plummer built its sequel. An AI coding agent helped generate the initial foundation from his 107-page prompt specification. The utility quickly drew massive attention across developer communities. However, widespread viral coverage created confusion around pricing, system support, and binary safety.

Our engineering team tested TMOG 1.0.0 RTM across our lab workstations. We inspected network traffic, verified code signatures, and benchmarked memory footprints against default system monitors. Here is our verified technical analysis of how TMOG performs.

## What is TMOG and how does it differ from Windows Task Manager?

TMOG (Task Manager OG) is a cross-platform system monitor built by Dave Plummer, the original author of Windows Task Manager. Unlike web-wrapped utilities, TMOG runs on a shared C++20 measuring engine paired with native platform frontends. Windows uses Win32 and Direct2D, macOS uses Swift with AppKit, and Linux uses Qt 6. It bypasses Electron entirely to hit a 60Hz telemetry refresh target with minimal system latency. The tool displays per-core CPU graphs, GPU engines, memory allocations, disk queues, and network sockets in real time. The free edition includes core views like Performance, Processes, Services, and Startup apps with zero telemetry or expiration dates. The $39.95 Pro tier adds Flight Recorder, which records seven telemetry panels into an exportable file for post-incident debugging. TMOG targets Windows 11, macOS 14+, and modern Linux distros, omitting Windows 10 support due to modern graphics API requirements.

Our lab tests show significant design differences between TMOG and the default Windows 11 Task Manager. While stock Task Manager relies on XAML Islands, TMOG renders directly through Direct2D for faster UI redraws.

## Who Dave Plummer is and why Task Manager matters

Dave W. Plummer wrote the original Windows Task Manager in his home office during the mid-1990s. Windows NT chief architect Dave Cutler reviewed and approved the utility, shipping it with Windows NT 4.0 in 1996.

Plummer kept the original executable tiny, compiling down to roughly 80KB. Microsoft developers still reference his legacy code, noting internal window classes named after him. Plummer also authored Windows ZIP folder integration and ported Space Cadet Pinball to NT. After leaving Microsoft in 2003, he founded the popular Dave's Garage channel. When evaluating system diagnostics, few engineers carry deeper firsthand authority.

## The specification behind the AI build process

Plummer began this project to test the actual limits of AI coding assistants. He wondered whether modern LLMs could generate industrial-grade software or merely produce unusable code.

He drafted a rigorous 107-page architectural specification describing every data structure, metric formula, and UI state. He then supplied this specification to Claude Code. The agent produced a functioning multi-platform scaffold in roughly four hours.

Plummer and two collaborators spent the next six weeks refining the codebase. They profiled system calls, optimized thread allocations, and debugged edge cases. Plummer emphasized that AI succeeds only when guided by an exhaustive technical blueprint. Without strict specifications, AI tools generate unreliable code.

## Debunking viral myths and false claims

Online coverage generated several misleading claims regarding TMOG. We verified the actual facts:

- **Myth: Microsoft created or adopted TMOG.** TMOG is strictly an independent utility created by Dave Plummer. It is not part of Windows Update or the Microsoft Store.
- **Myth: TMOG supports Windows 10.** TMOG requires Windows 11. It leverages DirectComposition APIs unavailable in older Windows builds.
- **Myth: TMOG is open source.** The project remains closed-source proprietary software. No public GitHub repository exists.
- **Myth: Pro requires a monthly subscription.** Pro is a one-time perpetual purchase of $39.95 managed through Lemon Squeezy.
- **Myth: Third-party download mirrors are safe.** Early beta builds lacked digital signatures. Always download directly from tmog.org.

## Installer security and Authenticode verification

Security forms a critical part of evaluating third-party admin utilities. Utilities running with elevated rights require rigorous verification.

On our workbench, we routed TMOG network traffic through an isolated gateway. The application contacted no cloud servers for telemetry, process monitoring, or hardware profiling. The software executes only standard HTTPS GET requests to check for version updates and validate Pro license tokens.

Early beta releases arrived unsigned. However, the Windows 1.0.0 RTM installer features a valid Authenticode signature issued to David Plummer by SSL.com.

Run this PowerShell command to verify your downloaded installer before running setup:

```powershell
# Verify TMOG installer Authenticode signature and file hash
$Installer = "$HOME\Downloads\TMOG-Task-Manager-Setup.exe"

# 1. Check Authenticode digital signature
Get-AuthenticodeSignature -FilePath $Installer | Format-List Status, StatusMessage, SignerCertificate

# 2. Compute SHA-256 checksum
Get-FileHash -Path $Installer -Algorithm SHA256
```

Our lab confirmed a status of **Valid** on the official 1.0.0 executable (`96AECAD1C3F7FF14B7E4B29E75FEA358680A987531EFA8516C834ED38B9E0B78`). If your local check shows an invalid signature, delete the binary immediately.

## Performance benchmarks on our test bench

We evaluated TMOG 1.0.0 alongside stock Windows 11 Task Manager on our test bench. We observed noticeable trade-offs in resource consumption.

Stock Task Manager typically consumes 100MB of RAM and under 1% CPU utilization during idle monitoring. In our tests, TMOG drew between 115MB and 130MB of RAM. Its 60Hz animation loop consumed 2% to 4% CPU on an AMD Ryzen 9 7950X workstation.

Reducing the interface refresh rate to 15Hz inside app settings dropped CPU consumption below 1%. ## Free vs Pro: deciding if $39.95 is justified

TMOG Free delivers full real-time monitoring with no time limits. You can monitor CPU cores, GPU usage, network bandwidth, and active services without paying.

TMOG Pro costs $39.95 and targets professional sysadmins. Its standout feature is Flight Recorder. Flight Recorder continuously logs seven telemetry streams into a compact `.tmogtrace` file.

When a server or workstation stutters overnight, you can scrub backward through the timeline. You can pinpoint exactly which process exhausted RAM or spiked disk queues. For developers managing heavy virtualization, this works well alongside our [WSL2 auto memory reclaim runbook](/blog/why-wsl2-vmmem-wont-free-ram-auto-memory-reclaim-fix).

However, casual desktop users rarely require post-incident trace scrubbing. If you simply want responsive system meters, the free tier meets everyday requirements.
