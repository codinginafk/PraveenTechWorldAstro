Managing a fleet of Linux web servers, staging environments, and database nodes usually leads to a dilemma: configure heavy enterprise monitoring stacks (like Prometheus, Grafana, or Zabbix) that consume 2GB+ RAM per node, or manually SSH into each server every weekend to check disk quotas.

On our IT workbench, our team manages four cloud VPS instances. To eliminate manual SSH routine checks, we prompted **DeepSeek** to architect a lightweight, multi-threaded **Python server health check daemon**.

While the AI's first draft contained severe SSH connection pooling bugs, our revised production script checks 4 servers across CPU, RAM, NVMe storage, and failed systemd services in under **6 seconds**.

Here is our complete prompt breakdown, technical fixes, and production Python code.

## 📊 DeepSeek Health Checker: Initial Bugs vs. Production Fixes

| Problem Area | DeepSeek Initial Draft | Workbench Production Fix |
|:---|:---|:---|
| **SSH Handshakes** | Opened 12 separate SSH connections per server | **Single pooled connection** per host via `asyncssh` |
| **Error Handling** | Unhandled `PermissionDenied` crashed entire loop | Isolated `try/except` per server; logs offline nodes |
| **Alert Volume** | Sent 47 identical Slack alerts in 10 minutes | **1-hour alert deduplication cache** by host/metric |
| **Execution Time** | 45 Seconds (Sequential loop) | **6.2 Seconds** (Asynchronous parallel execution) |

## ⚡ Production-Ready Python Health Check Script

Save this script as `health_checker.py`:

```python
#!/usr/bin/env python3
import asyncio
import asyncssh
import yaml
import json
import requests
from datetime import datetime

# Alert state cache to prevent spamming webhooks
SENT_ALERTS = {}

async def check_host(name, cfg, thresholds, webhook_url):
    results = {"name": name, "status": "UP", "metrics": {}, "alerts": []}
    try:
        async with asyncssh.connect(
            cfg["host"], 
            port=cfg.get("port", 22), 
            username=cfg["user"], 
            client_keys=[cfg["key_path"]],
            known_hosts=None
        ) as conn:
            # 1. CPU Load Average
            load_res = await conn.run("cat /proc/loadavg", check=True)
            load_1m = float(load_res.stdout.split()[0])
            results["metrics"]["cpu_load"] = load_1m
            if load_1m > thresholds.get("cpu_load", 2.0):
                results["alerts"].append(f"High CPU Load: {load_1m}")

            # 2. Disk Usage on Root Partition
            df_res = await conn.run("df -h / | awk 'NR==2 {print $5}' | tr -d '%'", check=True)
            disk_pct = int(df_res.stdout.strip())
            results["metrics"]["disk_usage"] = disk_pct
            if disk_pct > thresholds.get("disk_usage", 80):
                results["alerts"].append(f"High Disk Usage: {disk_pct}%")

            # 3. Failed Systemd Units
            failed_res = await conn.run("systemctl --failed --no-legend | wc -l", check=True)
            failed_count = int(failed_res.stdout.strip())
            results["metrics"]["failed_services"] = failed_count
            if failed_count > 0:
                results["alerts"].append(f"{failed_count} Failed Systemd Services")

    except Exception as e:
        results["status"] = "OFFLINE"
        results["alerts"].append(f"Connection Error: {str(e)}")

    # Send deduplicated webhook alerts
    if results["alerts"] and webhook_url:
        for alert in results["alerts"]:
            cache_key = f"{name}_{alert}"
            now = datetime.now().timestamp()
            if cache_key not in SENT_ALERTS or (now - SENT_ALERTS[cache_key]) > 3600:
                SENT_ALERTS[cache_key] = now
                payload = {"text": f"🚨 *[ALERT] Server {name}*: {alert}"}
                try:
                    requests.post(webhook_url, json=payload, timeout=5)
                except Exception:
                    pass

    return results

async def main():
    with open("servers.yml", "r") as f:
        config = yaml.safe_load(f)

    tasks = [
        check_host(name, cfg, config["thresholds"], config.get("webhook"))
        for name, cfg in config["servers"].items()
    ]
    
    reports = await asyncio.gather(*tasks)
    print(f"[{datetime.now().strftime('%Y-%m-%d %H:%M:%S')}] Health Check Completed:")
    for r in reports:
        print(f" - {r['name']} ({r['status']}): {r['metrics']} | Alerts: {len(r['alerts'])}")

if __name__ == "__main__":
    asyncio.run(main())
```bash
