> **Quick answer:** To track content engagement in Google Analytics 4 (GA4), monitor three core metrics in **Reports > Engagement > Pages and screens**: (1) **Engagement Rate** (percentage of sessions lasting 10+ seconds, viewing 2+ pages, or triggering a conversion), (2) **Average Engagement Time** (active foreground dwell time, benchmarked at 90+ seconds for technical guides), and (3) **Scrolls** (automated 90% scroll depth events via Enhanced Measurement). To measure granular reading milestones at 25%, 50%, and 75%, deploy a custom `gtag.js` scroll listener or GTM trigger rather than relying solely on Google's default 90% threshold.

When our team audited our early traffic in Universal Analytics, our analytics dashboard painted a confusing picture. Several of our most popular 2,500-word troubleshooting guides registered an alarming **74% bounce rate**, yet readers frequently sent emails thanking us for solving their production bugs.

The issue was Universal Analytics' obsolete measurement model: if an engineer arrived via Google, read our runbook for eight minutes, resolved their server outage, and closed the browser tab, UA logged that session as a failure.

Migrating to **Google Analytics 4 (GA4)** fundamentally fixed this tracking blindspot by replacing raw pageview bounce rates with **active user engagement telemetry**.

Here is our engineering team's comprehensive guide to configuring GA4 content engagement tracking, the comparative metrics matrix, custom `gtag.js` milestone scripts, and our weekly optimization workflow.

## 1. The GA4 Session Engagement State Machine

**Understanding how GA4 qualifies an engaged session prevents misinterpreting traffic drops and helps diagnose real user drop-off.**

```
+-------------------------------------------------------------------------+
|                   GA4 SESSION ENGAGEMENT LOGIC FLOW                     |
+-------------------------------------------------------------------------+
|                                                                         |
|  [ User Arrives on Article URL ] ──► `session_start` & `first_visit`    |
|               │                                                         |
|               ├─► Exits in under 10s (0 conversions, 1 page)            |
|               │   └── Flagged as: [ UNENGAGED / BOUNCED SESSION ]       |
|               │                                                         |
|               ▼ Meets ANY of these 3 criteria:                          |
|  ┌───────────────────────────────────────────────────────────────────┐  |
|  │  1. Active foreground engagement time >= 10.0 seconds             │  |
|  │  2. Triggers 1 or more key conversion events (e.g., signup)       │  |
|  │  3. Views 2 or more distinct pages or screens                     │  |
|  └───────────────────────────────────────────────────────────────────┘  |
|               │                                                         |
|               ▼                                                         |
|  [ Flagged as: ENGAGED SESSION (`session_engaged = 1`) ]                 |
|  └── Feeds into: Engagement Rate = (Engaged Sessions / Total Sessions)  |
|                                                                         |
+-------------------------------------------------------------------------+
```

## 2. GA4 Engagement Metrics vs. Universal Analytics Comparison Matrix

**GA4 replaces negative failure metrics with positive interaction signals that reflect actual reader attention.**

| Engagement Metric | GA4 Definition | Universal Analytics Equivalent | Healthy Blog Benchmark | Primary Diagnostic Action |
|---|---|---|:---:|---|
| **Engagement Rate** | % of sessions with 10+ sec active time, 2+ pages, or 1+ conversion | Inverted Bounce Rate (100% - Bounce Rate) | **60% – 75%** | If under 45%, rewrite opening 100 words to answer search intent faster |
| **Average Engagement Time** | Cumulative seconds a page was in the active browser foreground | Avg. Session Duration (Misleading) | **90s – 180s** | If under 45s on 1,500w post, add bold callouts and comparison tables |
| **Engaged Sessions Per User** | Total engaged sessions divided by total unique users | N/A (Brand Loyalty Signal) | **1.2 – 1.6** | If close to 1.0, add contextual internal cross-links to sister guides |
| **Scrolls (`scroll`)** | Fires automatically when a reader reaches 90% page depth | Custom Event Required | **30% – 50%** | If under 25%, audit page layout for premature exit points or dead ends |
| **Bounce Rate (GA4)** | % of sessions that were NOT engaged (100% - Engagement Rate) | Single-page exit sessions | **25% – 40%** | Focus on reducing bounce rate by eliminating intrusive popups |

## 4. Deploying Granular Scroll Milestone Tracking (25%, 50%, 75%)

**GA4's native Enhanced Measurement only fires a `scroll` event at 90% depth. To identify exactly where readers drop off, deploy this lightweight custom listener.**

Add this zero-dependency vanilla JavaScript snippet to your site's header layout or tag manager:

```javascript
// scripts/ga4-scroll-milestones.js
(function() {
  if (typeof window === 'undefined') return;

  const milestones = [25, 50, 75];
  const triggered = {};

  function getScrollPercent() {
    const h = document.documentElement;
    const b = document.body;
    const st = 'scrollTop';
    const sh = 'scrollHeight';
    return Math.round(((h[st] || b[st]) / ((h[sh] || b[sh]) - h.clientHeight)) * 100);
  }

  window.addEventListener('scroll', function() {
    const currentPercent = getScrollPercent();

    milestones.forEach(function(milestone) {
      if (currentPercent >= milestone && !triggered[milestone]) {
        triggered[milestone] = true;
        
        // Push custom event to GA4 dataLayer / gtag
        if (typeof gtag === 'function') {
          gtag('event', 'scroll_milestone', {
            depth_threshold: milestone,
            page_title: document.title,
            page_location: window.location.href
          });
        }
      }
    });
  }, { passive: true });
})();
```

## 5. BigQuery SQL: Extracting True Reading Time by Page

**GA4 standard reports round engagement time. If your property is linked to Google BigQuery, run this query to calculate exact active reading dwell time per URL:**

```sql
-- queries/engaged_reading_time.sql
-- Calculates active engagement time and scroll completion in GA4 BigQuery export
SELECT
  (SELECT value.string_value FROM UNNEST(event_params) WHERE key = 'page_location') AS page_url,
  COUNT(DISTINCT user_pseudo_id) AS total_users,
  COUNT(DISTINCT CONCAT(user_pseudo_id, (SELECT value.int_value FROM UNNEST(event_params) WHERE key = 'ga_session_id'))) AS total_sessions,
  ROUND(SUM(CASE WHEN event_name = 'user_engagement' THEN 
    (SELECT value.int_value FROM UNNEST(event_params) WHERE key = 'engagement_time_msec') ELSE 0 END) / 1000.0 / 60.0, 2) AS total_engaged_minutes,
  ROUND(SAFE_DIVIDE(
    SUM(CASE WHEN event_name = 'user_engagement' THEN (SELECT value.int_value FROM UNNEST(event_params) WHERE key = 'engagement_time_msec') ELSE 0 END) / 1000.0,
    COUNT(DISTINCT CONCAT(user_pseudo_id, (SELECT value.int_value FROM UNNEST(event_params) WHERE key = 'ga_session_id')))
  ), 1) AS avg_engagement_seconds_per_session
FROM
  `your-gcp-project.analytics_123456789.events_*`
WHERE
  _TABLE_SUFFIX BETWEEN '20260801' AND '20260831'
GROUP BY
  page_url
HAVING
  total_sessions >= 10
ORDER BY
  avg_engagement_seconds_per_session DESC;
```

## 6. How Our Team Uses Engagement Data to Fix Underperforming Content

**Engagement telemetry tells you exactly what part of an article is failing before search engine algorithms downgrade your positions.**

1. **High Traffic + Low Engagement Rate (Under 45%):**
   - **Diagnosis:** Misleading title or slow introductory fluff. Readers click expecting a direct solution but hit a wall of theoretical text.
   - **Action:** Add a 45-word direct-answer callout in the first viewport.
2. **High Engagement Rate + Low Scroll Depth (Under 20%):**
   - **Diagnosis:** Readers find what they need immediately in section 1, but abandon the rest of the guide.
   - **Action:** Add an interactive index with jump links and relevant internal cross-links early in the body.
3. **High Engagement Time (3m+) + Zero Conversions/Clicks:**
   - **Diagnosis:** The content is exceptional, but offers no logical next step.
   - **Action:** Embed related technical runbooks and next-step guides directly into the conclusion.

## Decision Summary: Your Weekly GA4 Engagement Cadence

- **Every Monday:** Open **Reports > Engagement > Pages and screens** and sort by *Average Engagement Time* ascending. Identify any high-traffic article averaging under 45 seconds.
- **Every Month:** Cross-reference GA4 engagement rates with Google Search Console impressions. Prioritize content rewrites on pages sitting in positions 6–15 with engagement rates below 50%.
- **Never rely solely on default 90% scrolls:** Deploy the custom `gtag.js` milestone script to see whether readers are exiting at the 25% or 50% mark.
