## ⚡ 3. Automation & Infrastructure: Self-Hosted Micro-SaaS

**Summary:** Deploying open-source automation and password management via Docker eliminates $500+/year in recurring cloud fees while keeping API secrets on your private network.

### n8n vs. Zapier
Zapier charges $20 to $50/month for a paltry 750 to 2,000 tasks. Our workbench runs automated grading pipelines and customer notifications processing over 45,000 tasks monthly. Running **n8n** locally via Docker gives our team unlimited executions, custom JavaScript/Python execution nodes, and direct webhook listeners.

Here is our production `docker-compose.yml` for self-hosting n8n alongside Vaultwarden (the lightweight Rust-based Bitwarden-compatible password vault):

```yaml
# docker-compose.yml: Production Self-Hosted FOSS Productivity Stack
version: '3.8'

services:
  n8n:
    image: docker.n8n.io/n8nio/n8n:latest
    container_name: ptw_n8n_automation
    restart: unless-stopped
    ports:
      - "5678:5678"
    environment:
      - N8N_BASIC_AUTH_ACTIVE=true
      - N8N_BASIC_AUTH_USER=sysadmin
      - N8N_BASIC_AUTH_PASSWORD=WorkbenchSecretPassword2026!
      - N8N_HOST=localhost
      - N8N_PORT=5678
      - N8N_PROTOCOL=http
      - EXECUTIONS_DATA_PRUNE=true
      - EXECUTIONS_DATA_MAX_AGE=168
      - GENERIC_TIMEZONE=Asia/Dubai
    volumes:
      - ./n8n_data:/home/node/.n8n
    networks:
      - foss_network

  vaultwarden:
    image: vaultwarden/server:latest
    container_name: ptw_vaultwarden
    restart: unless-stopped
    ports:
      - "8080:80"
    environment:
      - SIGNUPS_ALLOWED=false
      - WEBSOCKET_ENABLED=true
      - SHOW_PASSWORD_HINT=false
    volumes:
      - ./vault_data:/data
    networks:
      - foss_network

networks:
  foss_network:
    driver: bridge
```

### Launching the Stack
Run the following command in the directory containing `docker-compose.yml`:
```bash
docker compose up -d
```
Your n8n automation console is instantly available at `http://localhost:5678`, and your private Bitwarden-compatible vault is reachable at `http://localhost:8080`.

## 🛠️ 4. One-Command Workstation Setup: Automated WinGet Script

**Summary:** Manually downloading installers from web browsers is slow and error-prone. Use our PowerShell deployment script to provision an entire FOSS workstation in under 2 minutes.

To standardize new laptops and test benches, our team created `deploy_foss_workstation.ps1`. It uses the native Windows Package Manager (`winget`) to silently install and configure the entire open-source toolchain with official publisher hash verification.

```powershell
<#
.SYNOPSIS
    Automated FOSS Workstation Provisioning Script (PraveenTechWorld 2026).
.DESCRIPTION
    Installs audited free and open-source alternatives to Adobe, Microsoft 365,
    Notion, 1Password, and WinZip using Windows Package Manager (WinGet).
#>

[CmdletBinding()]
param(
    [switch]$SkipMedia,
    [switch]$SkipOffice
)

Write-Host "============================================================" -ForegroundColor Cyan
Write-Host "  PraveenTechWorld FOSS Workstation Deployment Engine 2026   " -ForegroundColor Cyan
Write-Host "============================================================" -ForegroundColor Cyan

# Verify WinGet availability
if (-not (Get-Command winget -ErrorAction SilentlyContinue)) {
    Write-Error "WinGet (Windows Package Manager) is not available. Please install the App Installer from the Microsoft Store."
    exit 1
}

$corePackages = @(
    @{ Id = "7zip.7zip"; Name = "7-Zip (Replaces WinRAR)" },
    @{ Id = "Obsidian.Obsidian"; Name = "Obsidian (Replaces Notion)" },
    @{ Id = "Bitwarden.Bitwarden"; Name = "Bitwarden (Replaces 1Password)" },
    @{ Id = "ShareX.ShareX"; Name = "ShareX (Replaces Loom/Snagit)" },
    @{ Id = "VideoLAN.VLC"; Name = "VLC Media Player (Replaces Paid Codecs)" }
)

$mediaPackages = @(
    @{ Id = "GIMP.GIMP"; Name = "GIMP 3.0 (Replaces Photoshop)" },
    @{ Id = "Inkscape.Inkscape"; Name = "Inkscape (Replaces Illustrator)" },
    @{ Id = "OBSProject.OBSStudio"; Name = "OBS Studio (Replaces Camtasia)" },
    @{ Id = "Audacity.Audacity"; Name = "Audacity (Replaces Audition)" }
)

$officePackages = @(
    @{ Id = "TheDocumentFoundation.LibreOffice"; Name = "LibreOffice 24 (Replaces M365)" }
)

$installList = @($corePackages)
if (-not $SkipMedia) { $installList += $mediaPackages }
if (-not $SkipOffice) { $installList += $officePackages }

Write-Host "`n[+] Installing $($installList.Count) enterprise-audited FOSS applications..." -ForegroundColor Yellow

$successCount = 0
$failCount = 0

foreach ($pkg in $installList) {
    Write-Host "`n--> Deploying: $($pkg.Name) [$($pkg.Id)]..." -ForegroundColor Green
    $process = Start-Process -FilePath "winget" `
        -ArgumentList "install --id $($pkg.Id) -e --silent --accept-source-agreements --accept-package-agreements" `
        -NoNewWindow -PassThru -Wait

    if ($process.ExitCode -eq 0 -or $process.ExitCode -eq -1978335189) { # 0 = Success, -1978335189 = Already installed
        Write-Host "    [OK] Successfully deployed: $($pkg.Name)" -ForegroundColor Cyan
        $successCount++
    } else {
        Write-Warning "    [WARN] WinGet returned exit code $($process.ExitCode) for $($pkg.Id)"
        $failCount++
    }
}

Write-Host "`n============================================================" -ForegroundColor Cyan
Write-Host "  Provisioning Complete: $successCount Installed | $failCount Failed  " -ForegroundColor Green
Write-Host "  Estimated Annual Recurring Savings: `$2,450.00 USD/seat    " -ForegroundColor Green
Write-Host "============================================================" -ForegroundColor Cyan
```

To run the script on any fresh Windows 11 machine, open an elevated PowerShell prompt:
```powershell
Set-ExecutionPolicy RemoteSigned -Scope Process -Force
.\deploy_foss_workstation.ps1
```

## 🔒 5. Security & Maintenance: Keeping Free Software Hardened

**Summary:** Open-source software security depends on verified download provenance and automated patch maintenance.

When migrating to open-source software, follow three fundamental operational rules established on our workbench:

1. **Verify Binary Signatures & Hashes:** Never download FOSS installers from third-party freeware portals (like Softpedia or Download.cnet). Always obtain binaries from official GitHub releases, official developer domains (`.org`), or signed package repositories like WinGet and Homebrew.
2. **Automate Updates with Package Managers:** Rather than checking for updates manually inside each application, run a weekly one-line maintenance command in Windows Terminal:
   ```powershell
   winget upgrade --all --include-unknown
   ```
   This silently checks and updates every installed tool across your system in minutes.
3. **Audit Local Vault Backups:** For password managers like Bitwarden or notes like Obsidian, configure automated encrypted backups using Syncthing or an external SSD. Because you own the storage, maintaining backup hygiene is your responsibility.
