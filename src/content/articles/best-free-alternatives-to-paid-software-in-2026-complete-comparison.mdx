## ⚡ Self-Hosting Recipe: Run n8n Automation via Docker Compose

Why pay $20/month for Zapier limits when you can run **n8n** locally with unlimited workflow triggers?

```yaml
# docker-compose.yml for Local n8n Workflow Automation
version: '3.8'

services:
  n8n:
    image: docker.n8n.io/n8nio/n8n:latest
    container_name: n8n_server
    restart: always
    ports:
      - "5678:5678"
    environment:
      - N8N_BASIC_AUTH_ACTIVE=true
      - N8N_BASIC_AUTH_USER=admin
      - N8N_BASIC_AUTH_PASSWORD=SecurePassword2026!
      - N8N_HOST=localhost
      - WEBHOOK_URL=http://localhost:5678/
    volumes:
      - ./n8n_data:/home/node/.n8n
```bash

### Run with one command:
```bash
docker compose up -d
```
Access your self-hosted automation dashboard at `http://localhost:5678`.

## 1. Creative & Media Alternatives

### GIMP & Photopea (Replaces Adobe Photoshop)
- **GIMP 3.0** brings modern non-destructive editing, full GTK3 UI redesign, and CMYK color space workflows.
- **Photopea** is a free, web-based image editor that runs entirely in your browser with identical Photoshop keyboard shortcuts and full `.psd` layer support.

### DaVinci Resolve (Replaces Adobe Premiere Pro)
- The free version of **Blackmagic DaVinci Resolve** offers node-based color grading, multi-cam editing, Fairlight audio mastering, and GPU-accelerated export.
- Used in award-winning Hollywood productions; zero recurring subscription.

### OBS Studio (Replaces Camtasia & Loom)
- Unlimited 4K/60FPS screen recording with multi-audio track routing and zero watermarks.

## 2. Productivity & Operations

### Obsidian & Joplin (Replaces Notion & Evernote)
- **Obsidian** stores your notes in plain markdown (`.md`) files on your local drive with bidirectional link graph visualization.
- 100% private, instantaneous search, and unaffected by cloud outages.

### LibreOffice 24.x (Replaces Microsoft Office)
- Comprehensive desktop suite (Writer, Calc, Impress, Draw) with native `.docx` and `.xlsx` support.

### Cal.com (Replaces Calendly)
- Open-source appointment booking platform with Google Calendar, Outlook, and Zoom/Jitsi API sync.

## 3. Developer & Infrastructure

### Supabase (Replaces Google Firebase)
- Open-source Postgres database with real-time subscriptions, row-level security (RLS), instant REST/GraphQL APIs, and auth handling.

### PostHog (Replaces Mixpanel & Hotjar)
- All-in-one product analytics, session replay screen recordings, feature flags, and A/B testing suite.
