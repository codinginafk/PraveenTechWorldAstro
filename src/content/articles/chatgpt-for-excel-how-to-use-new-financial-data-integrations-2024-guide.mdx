## 4. Standalone Financial Data Script: Multi-Ticker Valuation Builder

**Instead of manual copying, run this standalone Python script on your dev machine to pull live fundamentals, calculate valuation multiples, and generate a fully formatted Excel financial model:**

```python
#!/usr/bin/env python3
"""
scripts/excel_financial_puller.py
Pulls live fundamentals and generates a comparative valuation Excel model.
Requires: pip install pandas openpyxl yfinance
"""

import sys
import pandas as pd
import yfinance as yf

DEFAULT_TICKERS = ["AAPL", "MSFT", "GOOGL", "AMZN", "NVDA"]

def build_valuation_model(tickers, output_file="Financial_Model_2026.xlsx"):
    print(f"[*] Fetching financial data for: {', '.join(tickers)}...")
    records = []

    for ticker in tickers:
        stock = yf.Ticker(ticker)
        info = stock.info
        
        records.append({
            "Ticker": ticker,
            "Company Name": info.get("shortName", "N/A"),
            "Current Price ($)": info.get("currentPrice", 0.0),
            "Market Cap ($B)": round(info.get("marketCap", 0) / 1e9, 2),
            "Trailing P/E": info.get("trailingPE", "N/A"),
            "Forward P/E": info.get("forwardPE", "N/A"),
            "EV / EBITDA": info.get("enterpriseToEbitda", "N/A"),
            "Profit Margin (%)": round(info.get("profitMargins", 0) * 100, 2) if info.get("profitMargins") else "N/A",
            "Free Cash Flow ($B)": round(info.get("freeCashflow", 0) / 1e9, 2) if info.get("freeCashflow") else "N/A"
        })

    df = pd.DataFrame(records)

    with pd.ExcelWriter(output_file, engine="openpyxl") as writer:
        df.to_excel(writer, sheet_name="Valuation Multiples", index=False)
        
    print(f"[SUCCESS ✅] Model built and saved to: {output_file}")

if __name__ == "__main__":
    ticker_args = sys.argv[1:] if len(sys.argv) > 1 else DEFAULT_TICKERS
    build_valuation_model(ticker_args)
```

## 5. Office Script Automation: One-Click Table Formatting

**For Microsoft 365 cloud users, use this native TypeScript Office Script to apply professional accounting formats to raw AI-generated ranges automatically:**

```typescript
// scripts/FormatFinancialTable.ts
function main(workbook: ExcelScript.Workbook) {
  let sheet = workbook.getActiveWorksheet();
  let tableRange = sheet.getUsedRange();

  // 1. Format Header Row (Dark Slate Navy + White Text)
  let headerRow = tableRange.getRow(0);
  headerRow.getFormat().getFill().setColor("#1E293B");
  headerRow.getFormat().getFont().setColor("#FFFFFF");
  headerRow.getFormat().getFont().setBold(true);

  // 2. Format Currency Columns (Columns C, D, I)
  tableRange.getColumn(2).getFormat().setHorizontalAlignment(ExcelScript.HorizontalAlignment.right);
  tableRange.getColumn(2).setNumberFormat("$#,##0.00");

  // 3. Apply Thin Grid Borders
  tableRange.getFormat().getRangeBorder(ExcelScript.BorderIndex.insideHorizontal).setStyle(ExcelScript.BorderLineStyle.thin);
  tableRange.getFormat().getRangeBorder(ExcelScript.BorderIndex.insideVertical).setStyle(ExcelScript.BorderLineStyle.thin);

  // 4. Auto-fit Column Widths
  tableRange.getFormat().autofitColumns();
  console.log("Financial table formatted to accounting standards.");
}
```

## 6. Critical Safeguards: How to Avoid Financial AI Hallucinations

**Large language models are probabilistic text generators, not deterministic calculators. Enforce these 4 validation rules when automating spreadsheets:**

1. **Never Let AI Calculate Complex Totals Directly:** Prompt the AI to output standard Excel mathematical formulas (`=SUM()`, `=XIRR()`, `=NPV()`) rather than raw computed sums. Formula-based cells allow deterministic recalculation and instant cell auditing.
2. **Standardize Fiscal Year Definitions:** Different companies operate on divergent fiscal calendars (e.g., Apple's Q1 ends in December, whereas Microsoft's Q1 ends in September). Always explicitly prompt the connector for calendar-adjusted or SEC filing-specific quarters.
3. **Verify Restated Financials:** Companies frequently restate historical earnings during mergers or accounting standard updates. Cross-check trailing twelve-month figures against raw 10-K filings.
4. **Audit Boundary Zero-Division:** Automated formulas must always wrap division expressions in `=IFERROR()` or `=IF(denominator=0, ...)` to prevent cascading `#DIV/0!` errors across dependent valuation tabs.
