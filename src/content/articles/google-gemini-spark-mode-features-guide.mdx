## 4. Troubleshooting Common Spark Mode Friction Points

**Most Gemini Spark Mode failures on Windows 11 trace back to headless Chrome sandbox conflicts, loopback port collisions on 9222, or missing MCP execution permissions.**

When running autonomous agents on Windows 11, the most frequent failure our team encountered on the workbench was Spark disconnecting from local browser sessions or timing out during MCP tool calls. Here is our direct diagnosis and triage runbook:

### Windows 11 Connection & Port 9222 Triage Matrix

| Symptom / Error Log | Root Cause on Windows 11 | Immediate Workbench Resolution |
| :--- | :--- | :--- |
| `ERR_CONNECTION_REFUSED 127.0.0.1:9222` | Chrome is running as a standard window without the debugging flag, or background `chrome.exe` tasks are locking port 9222 | Terminate all Chrome processes via PowerShell, then relaunch with `--remote-debugging-port=9222` |
| `HTTP 403 Forbidden / Invalid Host Header` | Chrome CDP security boundary rejecting WebSocket requests lacking a valid localhost origin | Pass `--remote-allow-origins="*"` alongside `--remote-debugging-port=9222` |
| `Session Storage / Authentication Desync` | Spark launches Chrome in a temporary clean profile instead of your active user session | Specify your user profile via `--user-data-dir="$env:LOCALAPPDATA\Google\Chrome\User Data"` |
| `MCP Tool Hang / Timeout 30s` | Windows Defender Firewall or third-party endpoint security blocking inbound localhost RPC bridge | Add a local firewall exception for Node.js / Python MCP server runtimes |
| `Codebase Index Stalled at 0%` | Repository contains large binary assets, `.git/objects`, or massive unignored vendor folders | Add a `.aiexclude` file ignoring `node_modules/`, `dist/`, and binary file extensions |

### How to Launch Chrome in CDP Debugging Mode

To attach Gemini Spark to your live authenticated Chrome session on Windows 11:

```powershell
# 1. Close all active Chrome processes
Get-Process -Name chrome -ErrorAction SilentlyContinue | Stop-Process -Force

# 2. Launch Chrome with CDP listening on port 9222
$ChromePath = "C:\Program Files\Google\Chrome\Application\chrome.exe"
if (-not (Test-Path $ChromePath)) {
    $ChromePath = "C:\Program Files (x86)\Google\Chrome\Application\chrome.exe"
}

Start-Process -FilePath $ChromePath -ArgumentList @(
    "--remote-debugging-port=9222",
    "--remote-allow-origins=*",
    "--user-data-dir=$env:LOCALAPPDATA\Google\Chrome\User Data"
)
```

### Automated Windows 11 Diagnostic Probe Script

To verify that your Windows 11 environment meets all prerequisites for Spark Mode and local MCP agent loops, run our workbench validation probe:

```powershell
# Test-GeminiSparkPrerequisites.ps1
# Diagnostics for Gemini Spark Mode on Windows 11
Write-Host "=== Gemini Spark Mode Windows 11 Diagnostic Probe ===" -ForegroundColor Cyan

# 1. Check Chrome Installation
$ChromePaths = @(
    "C:\Program Files\Google\Chrome\Application\chrome.exe",
    "C:\Program Files (x86)\Google\Chrome\Application\chrome.exe"
)
$ChromeFound = $ChromePaths | Where-Object { Test-Path $_ } | Select-Object -First 1
if ($ChromeFound) {
    Write-Host "[OK] Google Chrome detected at: $ChromeFound" -ForegroundColor Green
} else {
    Write-Host "[FAIL] Google Chrome not found in standard paths." -ForegroundColor Red
}

# 2. Check Port 9222 Listener Status
$Port9222 = Get-NetTCPConnection -LocalPort 9222 -State Listen -ErrorAction SilentlyContinue
if ($Port9222) {
    $Proc = Get-Process -Id $Port9222.OwningProcess -ErrorAction SilentlyContinue
    Write-Host "[OK] Port 9222 is ACTIVE (PID: $($Port9222.OwningProcess), Process: $($Proc.Name))" -ForegroundColor Green
} else {
    Write-Host "[WARN] Port 9222 is NOT listening. Chrome CDP is inactive." -ForegroundColor Yellow
}

# 3. Test HTTP CDP Endpoint
try {
    $CdpResponse = Invoke-RestMethod -Uri "http://127.0.0.1:9222/json/version" -TimeoutSec 2 -ErrorAction Stop
    Write-Host "[OK] CDP Endpoint reachable: Browser is $($CdpResponse.Browser)" -ForegroundColor Green
} catch {
    Write-Host "[WARN] CDP JSON endpoint unreachable at http://127.0.0.1:9222/json/version" -ForegroundColor Yellow
}

# 4. Check Node.js and Python Runtimes for MCP Tools
$NodeVer = (node -v 2>$null)
if ($NodeVer) {
    Write-Host "[OK] Node.js runtime detected: $NodeVer" -ForegroundColor Green
} else {
    Write-Host "[WARN] Node.js not detected in PATH (needed for JavaScript MCP servers)" -ForegroundColor Yellow
}

$PyVer = (python --version 2>$null)
if ($PyVer) {
    Write-Host "[OK] Python runtime detected: $PyVer" -ForegroundColor Green
} else {
    Write-Host "[WARN] Python not detected in PATH (needed for Python MCP servers)" -ForegroundColor Yellow
}

Write-Host "=== Diagnostic Probe Complete ===" -ForegroundColor Cyan
```
