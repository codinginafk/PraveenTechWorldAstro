Does resetting Windows remove viruses? Sometimes, but the option you choose matters. A reset or clean install can remove malware stored in the Windows installation, but it cannot certify every preserved file, attached drive, backup, or firmware component as clean. Treat it as one recovery step after containing the machine and protecting accounts.

Microsoft’s [Reset your PC documentation](https://support.microsoft.com/en-us/windows/reset-your-pc-0ef73740-b927-549b-b7c9-e6f2b48d275e) says **Keep my files** removes apps and settings while preserving personal files. **Remove everything** removes personal files, apps, and settings. Those choices answer the ordinary “will Windows be fresh?” question, but neither option should be presented as a laboratory-certified malware eradication rate. The safe answer depends on the infection and on what you reconnect afterward.

## Does resetting Windows remove viruses or malware?

**Short answer: Remove everything can remove malware stored in the Windows installation; Keep my files leaves more material to investigate.** A reset removes or rebuilds the operating-system environment. That helps with malicious services, installed programs, scheduled tasks, and startup entries stored on the system volume. It does not inspect every file you keep or every disk you later attach.

The reset screen offers two important choices:

- **Keep my files:** Windows removes installed apps and settings but keeps personal files. Use it for software corruption when you have no reason to suspect the preserved data.
- **Remove everything:** Windows removes personal files, apps, and settings. This is the more appropriate reset choice when you have backed up only trusted documents and need to discard the existing user environment.

Microsoft also offers **Cloud download** and **Local reinstall**. Cloud download fetches a fresh Windows image; Local reinstall uses files already on the PC. If you suspect the local recovery files are damaged, cloud download or installation media gives you a cleaner source. Keep a copy of the exact error message and your BitLocker recovery key before you start.

## Can Keep my files preserve malware?

**Yes, it can preserve files that need scanning, so do not call it a complete malware cleanup.** Personal documents are not automatically malicious, but malware often arrives inside downloads, scripts, browser extensions, cracked software, or macro-enabled documents. A reset that preserves those files can leave you with a clean Windows shell and an unsafe file set.

Before using Keep my files, copy only documents you can verify to a separate drive. Do not copy executable files, installers, browser profiles, scripts, or entire AppData folders. Scan the backup from a trusted system. If the infection involved account theft, save evidence such as suspicious email alerts and browser-session notifications before wiping the machine.

The option also removes applications. Plan to reinstall browsers, password managers, VPNs, and developer tools from their official websites. Do not restore an old installer simply because it is convenient. A fresh application download reduces the chance that a compromised package becomes the first program to run after the reset.

## What does Remove everything actually erase?

**Remove everything removes the Windows user environment, but it is not a forensic disk sanitization service.** Microsoft explains that the option removes personal files, apps, and settings. It also lets you choose whether to clean the data, but Microsoft notes that this cleaning is for consumers and does not meet government or industry data-erasure standards.

That distinction matters for malware troubleshooting. A standard reset is designed to make a PC usable again, not to prove that every sector, backup, firmware component, or external device is free of compromise. If you need a storage device sanitized before disposal, use a method appropriate to the drive and your organization’s policy rather than assuming Reset this PC is enough.

After selecting Remove everything, follow Microsoft’s prompts carefully. If you choose Cloud download, allow time for the download and keep the PC connected to reliable power. If the machine is encrypted, have the BitLocker recovery key available. A reset can take several minutes to show progress; interrupting it can create a second recovery problem.

## Should you use Defender Offline before or after a reset?

**Use Defender Offline when malware may hide while normal Windows is running, especially before deciding that a wipe is necessary.** Microsoft describes Defender Offline as a scan that runs from a trusted environment outside the normal Windows kernel. That makes it useful for threats that interfere with security tools or load early in startup.

Open **Windows Security > Virus & threat protection > Scan options > Microsoft Defender Offline scan**, then save your work and start the scan. Microsoft’s [malware troubleshooting guidance](https://support.microsoft.com/en-US/defender/troubleshoot-problems-with-detecting-and-removing-malware) also recommends Defender Offline when malware remains after a normal scan.

If the scan finds malware, record the detection name and follow the remediation instructions. If symptoms continue or the machine has irreversible changes, Microsoft recommends resetting or reinstalling Windows. Do not reconnect the computer to a sensitive network just to see whether the warning returns.

## When is a clean Windows install safer than Reset this PC?

**Choose installation media when you need a new Windows source or want to remove the existing system partitions.** Microsoft’s [installation-media guide](https://support.microsoft.com/en-us/windows/reinstall-windows-with-the-installation-media-d8369486-3e33-7d9c-dccc-859e2b022fc7) explains how to create media and perform a reinstall. Create it on a known-clean PC, verify that you selected the correct disk, and back up only data you have scanned.

During Windows Setup, the Custom installation path lets you remove the old Windows partitions and install into unallocated space. This removes storage-based operating-system files, recovery partitions, and old applications on that disk. It also destroys data, so confirm the disk number and keep the BitLocker key before deleting anything.

Do not claim that a clean install removes every rootkit. A storage reinstall cannot rewrite a malicious motherboard firmware image, and it cannot clean a second internal disk that you leave untouched. If the suspected threat survives a clean install, update firmware from the device manufacturer, enable Secure Boot, and contact the manufacturer or a qualified incident-response provider. Avoid repeatedly flashing firmware without a recovery plan.

## How do you stop a reset PC from getting reinfected?

**Treat the first hour after reinstall as a controlled rebuild, not a normal browsing session.** Use this order:

1. From a separate trusted device, change email, banking, work, and password-manager passwords. Revoke sessions and rotate recovery codes if a stealer may have been active.
2. Disconnect untrusted USB drives and secondary disks. Label each backup and scan it before opening files.
3. Finish Windows Update, install the current security intelligence updates, and run a full Microsoft Defender scan.
4. Reinstall applications from official vendor pages. Avoid cracked software, “driver pack” installers, and browser extensions you cannot verify.
5. Restore documents in small batches. Keep executable files and scripts out of the first restore until you have reviewed them.
6. Turn on Secure Boot and keep the device firmware current. Check BitLocker status before storing a recovery key.

## Does formatting an external drive remove a virus?

**Formatting an external drive removes its file-system contents, but it does not make every backup trustworthy by itself.** Scan the drive from a clean machine, delete unknown autorun files and installers, and restore only data you recognize. If the drive contains irreplaceable evidence, make a forensic image first instead of experimenting with it.

A USB installer is also not automatically safe. Download Windows media from Microsoft on a known-clean computer, keep the installer disconnected from the infected PC until you are ready, and never use a mystery ISO. If the PC immediately shows the same detection after reinstall, stop restoring files and investigate the source rather than repeating the reset.

Keep the recovery decision proportional to the evidence. A browser redirect that disappears after removing an extension does not require the same response as an information stealer that generated unfamiliar logins. For a work or banking computer, involve the organization’s security contact before wiping it because the device may contain logs needed to understand what happened. Photograph error messages, note the time of suspicious activity, and preserve the detection name. Those small records can matter more than another unverified “deep clean” claim.

If you are helping someone remotely, ask them to disconnect from the network and stop entering passwords before you send reset instructions. A reset is destructive and can erase evidence. Explain which files will be kept, which disks will be removed, and how the user will recover their BitLocker key. Clear expectations prevent a second incident caused by restoring every old download immediately after Windows starts.

Reset timing matters too. Microsoft’s recovery screen may pause for several minutes while it prepares the image, and a laptop should remain on mains power for the entire operation. Do not force a shutdown because the percentage counter has not moved for a short period. If the reset fails repeatedly, photograph the message, check available storage, and switch from Local reinstall to Cloud download or installation media instead of retrying the same damaged source.

### What should you back up before a malware reset?

**Back up irreplaceable personal data, not the whole profile.** Start with plain documents, photos, exported browser bookmarks, and project files you can open from another device. Avoid copying executable files, scripts, browser extensions, old installers, or an entire user profile. If you must preserve a suspicious file for analysis, place it in a clearly labelled quarantine folder and do not open it.

Write down the Windows edition, device model, installed applications, and any license information before wiping. Export Wi-Fi passwords only if you understand that this is sensitive data. Keep your BitLocker recovery key in a separate trusted location. These records turn a destructive reset into a controlled rebuild and reduce the temptation to restore an unverified backup.

If the computer belongs to a company, school, or family member who may have legal or financial exposure, stop before wiping it and contact the responsible administrator. A reset can remove useful evidence such as login times, detection names, and persistence clues. The fastest path to a usable PC is not always the safest path to understanding how the infection happened.

## Final decision: reset or reinstall?

**Use Remove everything for a straightforward Windows-level infection after a verified backup; use installation media when you need a fresh source or a partition-level rebuild; escalate suspected firmware compromise.** Keep my files is a convenience option, not evidence that malware is gone.

The practical sequence is Defender Offline, account protection, trusted backup, then either Remove everything or an installation-media reinstall. Microsoft documents the reset behavior and the offline scan; the remaining judgment depends on the infection, your backup hygiene, and whether another storage device or firmware could be involved. That boundary is safer than promising a percentage or calling any reset “guaranteed.”
