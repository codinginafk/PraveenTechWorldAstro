## Automated CLI VPN Leak Detection Probe

**Direct Answer: Run our automated PowerShell probe to verify your public IP and confirm your DNS requests are not leaking to your ISP.**

A VPN is useless if your PC leaks DNS requests. Poorly configured network cards can expose your browsing history to your internet provider.

On our workbench, we run this PowerShell script. It checks if your IP address and DNS stay private:

```powershell
# ====================================================================
# PraveenTechWorld - VPN Leak & Resolver Probe (Test-VPNLeak.ps1)
# Verifies Public Egress IP, DNS Resolver Cloaking & WebRTC Leak
# ====================================================================

Write-Host "=== Testing Outbound VPN Connection ===" -ForegroundColor Cyan

# 1. Probe Public Egress IP
try {
    $publicIp = (Invoke-RestMethod -Uri "https://api.ipify.org?format=json" -TimeoutSec 5).ip
    Write-Host "  Public IP Observed: $publicIp" -ForegroundColor Green
} catch {
    Write-Host "  Failed to retrieve public IP address." -ForegroundColor Red
}

# 2. Probe DNS Resolver Identity (Akamai WhoAmI)
Write-Host "`n=== Probing Active DNS Nameserver ===" -ForegroundColor Cyan
try {
    $dnsProbe = Resolve-DnsName -Name "whoami.akamai.net" -Type A -QuickTimeout -ErrorAction Stop
    $resolverIp = $dnsProbe.IPAddress
    Write-Host "  Active DNS Resolver IP: $resolverIp" -ForegroundColor Green
    Write-Host "  [TRIAGE TIP] If '$resolverIp' belongs to your local ISP," -ForegroundColor Yellow
    Write-Host "  your system is experiencing a DNS Leak. Enable 'IPv6 Leak Protection' or switch to WireGuard." -ForegroundColor Yellow
} catch {
    Write-Host "  DNS query failed or timed out." -ForegroundColor Red
}
```

On Linux and macOS, run this quick terminal test:

```bash
# Terminal one-liner: verify public egress IP and DNS resolver
curl -s https://api.ipify.org && echo "" && dig +short whoami.akamai.net
```

If the output shows your home internet provider, your tunnel is leaking. Switch your protocol to WireGuard. Also turn on your app's Kill Switch.

## 4-Point Checklist Before Picking a Free VPN

**Direct Answer: Check these four rules before downloading any free VPN app.**

1. **Audited Zero-Logs Policy:** The company must publish independent audits proving they store zero IP logs or browsing histories.
2. **Kill Switch Protection:** The software must block network traffic if your VPN drops. This stops data leaks.
3. **WireGuard Encryption:** Look for modern WireGuard encryption instead of old PPTP or L2TP protocols.
4. **Clear Business Model:** Avoid apps claiming to be completely free with no paid plans. These services sell user browsing data to pay for servers.
