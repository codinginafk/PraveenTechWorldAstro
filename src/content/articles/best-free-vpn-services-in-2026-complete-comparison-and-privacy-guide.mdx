## ⚡ How to Check for DNS Leaks via Command Line

Even if your VPN app shows "Connected", poorly configured TAP drivers can leak your DNS requests to your ISP. Run this check in Command Prompt or Terminal:

```cmd
:: Test DNS server resolution via CLI
nslookup whoami.akamai.net
```

If the returned IP address matches your home ISP (e.g., Comcast, Spectrum, BT) rather than your VPN provider's server address, your connection is leaking DNS queries. Switch your VPN protocol to **WireGuard** or enable **IPv6 Leak Protection** in the app settings.

## 5. Security & Privacy Audit Checklist

When evaluating any free VPN, verify these 4 mandatory security pillars:

1. **Audited Zero-Logs Policy:** The provider must undergo independent third-party code audits verifying that no IP addresses, timestamp logs, or browsing destinations are saved.
2. **Kill Switch Protection:** The application must automatically disable internet access if the VPN connection drops, preventing unencrypted data leaks.
3. **WireGuard Encryption:** Prioritize modern WireGuard (ChaCha20 encryption) over legacy PPTP or L2TP protocols.
4. **Transparent Freemium Model:** Avoid "100% free with no ads or paid tiers"—these apps monetize by harvesting user data.
