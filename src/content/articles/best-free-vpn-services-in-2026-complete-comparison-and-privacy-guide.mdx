## Automated CLI VPN Leak Detection Probe

**A VPN is useless if your operating system silently routes DNS queries or WebRTC packets through your physical network adapter.**

Even if your VPN application UI displays "Connected", misconfigured TAP/TUN virtual adapters or Windows multi-homed resolution can leak your real DNS requests directly to your ISP.

On our workbench, we run this automated PowerShell probe to verify that our egress traffic and DNS resolvers are completely cloaked:

```powershell
# ====================================================================
# PraveenTechWorld - VPN Leak & Resolver Probe (Test-VPNLeak.ps1)
# Verifies Public Egress IP, DNS Resolver Cloaking & WebRTC Leak
# ====================================================================

Write-Host "=== Testing Outbound VPN Connection ===" -ForegroundColor Cyan

# 1. Probe Public Egress IP
try {
    $publicIp = (Invoke-RestMethod -Uri "https://api.ipify.org?format=json" -TimeoutSec 5).ip
    Write-Host "  Public IP Observed: $publicIp" -ForegroundColor Green
} catch {
    Write-Host "  Failed to retrieve public IP address." -ForegroundColor Red
}

# 2. Probe DNS Resolver Identity (Akamai WhoAmI)
Write-Host "`n=== Probing Active DNS Nameserver ===" -ForegroundColor Cyan
try {
    $dnsProbe = Resolve-DnsName -Name "whoami.akamai.net" -Type A -QuickTimeout -ErrorAction Stop
    $resolverIp = $dnsProbe.IPAddress
    Write-Host "  Active DNS Resolver IP: $resolverIp" -ForegroundColor Green
    Write-Host "  [TRIAGE TIP] If '$resolverIp' belongs to your local ISP (Comcast/Spectrum/BT)," -ForegroundColor Yellow
    Write-Host "  your system is experiencing a DNS Leak. Enable 'IPv6 Leak Protection' or switch to WireGuard." -ForegroundColor Yellow
} catch {
    Write-Host "  DNS query failed or timed out." -ForegroundColor Red
}
```

For Linux and macOS terminals, run this single-line verification:

```bash
# Terminal one-liner: verify public egress IP and DNS resolver
curl -s https://api.ipify.org && echo "" && dig +short whoami.akamai.net
```

If the returned IP address matches your home ISP rather than your VPN provider's data center subnet, your tunnel is compromised. Switch your connection protocol to **WireGuard** or activate the provider's built-in **Kill Switch**.

## Four-Pillar VPN Security Audit Checklist

**Before downloading any free VPN, evaluate these four mandatory criteria to avoid rogue data harvesters.**

1. **Audited Zero-Logs Policy:** The provider must undergo independent third-party code audits verifying that no IP addresses, timestamp logs, or browsing destinations are saved.
2. **Kill Switch Protection:** The application must automatically disable internet access if the VPN connection drops, preventing unencrypted data leaks.
3. **WireGuard Encryption:** Prioritize modern WireGuard (ChaCha20-Poly1305 encryption) over legacy PPTP or L2TP protocols.
4. **Transparent Freemium Model:** Avoid "100% free with no ads or paid tiers"—these apps monetize by harvesting and selling user data.
