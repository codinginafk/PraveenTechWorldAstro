## 3. Automated Broken Link Scanner (Python Tool)

**Manually clicking through external links on resource hubs is tedious and error-prone. We built this automated Python tool to scan resource pages and report dead links instantly.**

Save this script as `scripts/find_broken_links.py` and run it against candidate resource directories:

```python
#!/usr/bin/env python3
"""
scripts/find_broken_links.py
Scans target technical resource pages for broken external links (HTTP 404/500).
Identifies prime replacement link opportunities.
"""

import sys
import requests
from bs4 import BeautifulSoup
from urllib.parse import urljoin, urlparse

HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0.0.0 Safari/537.36"
}

def scan_page_for_dead_links(target_url: str):
    print(f"[*] Fetching target page: {target_url}...")
    try:
        res = requests.get(target_url, headers=HEADERS, timeout=12)
        res.raise_for_status()
    except Exception as e:
        print(f"[!] Error accessing {target_url}: {e}")
        return

    soup = BeautifulSoup(res.text, "html.parser")
    links = soup.find_all("a", href=True)
    target_domain = urlparse(target_url).netloc
    external_links = set()

    for tag in links:
        href = urljoin(target_url, tag["href"])
        parsed = urlparse(href)
        if parsed.scheme in ["http", "https"] and parsed.netloc != target_domain:
            external_links.add(href)

    print(f"[*] Found {len(external_links)} unique external links. Verifying health...\n")
    dead_links = []

    for link in external_links:
        try:
            r = requests.head(link, headers=HEADERS, timeout=8, allow_redirects=True)
            if r.status_code >= 400:
                print(f"[DEAD ❌] HTTP {r.status_code} -> {link}")
                dead_links.append((link, r.status_code))
        except requests.RequestException:
            print(f"[DEAD ❌] TIMEOUT/ERR -> {link}")
            dead_links.append((link, "TIMEOUT"))

    print("\n" + "="*60)
    print(f"SCAN SUMMARY: {len(dead_links)} broken link opportunities identified.")
    print("="*60)
    for dead, code in dead_links:
        print(f" - {dead} (Status: {code})")

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("Usage: python find_broken_links.py <https://target-resource-page.com>")
        sys.exit(1)
    scan_page_for_dead_links(sys.argv[1])
```

## 5. Verifying Backlink Equity with PowerShell

**Never assume an earned backlink is passing PageRank without verifying its HTML attributes.**

Use this PowerShell script to inspect any referring URL and confirm whether the backlink is `dofollow` or tagged with `nofollow`/`sponsored`:

```powershell
# scripts/Verify-Backlink.ps1
param (
    [string]$ReferringUrl = "https://example-partner.com/resources",
    [string]$TargetDomain = "praveentechworld.com"
)

Write-Host "[*] Inspecting backlink equity on $ReferringUrl..." -ForegroundColor Cyan
$response = Invoke-WebRequest -Uri $ReferringUrl -UserAgent "Mozilla/5.0"
$matchedLinks = $response.Links | Where-Object { $_.href -match $TargetDomain }

if (-not $matchedLinks) {
    Write-Host "[FAIL ❌] No link to $TargetDomain found on page!" -ForegroundColor Red
    exit 1
}

foreach ($link in $matchedLinks) {
    $rel = $link.rel
    Write-Host "`nFound Link:" -ForegroundColor Yellow
    Write-Host "  Href: $($link.href)"
    Write-Host "  Text: $($link.innerText)"
    Write-Host "  Rel:  $(if ($rel) { $rel } else { 'dofollow (No rel attribute)' })"

    if ($rel -match "nofollow|sponsored|ugc") {
        Write-Host "  Status: ⚠️ LINK IS RESTRICTED ($rel)" -ForegroundColor Yellow
    } else {
        Write-Host "  Status: ✅ FULL EQUITY (DOFOLLOW)" -ForegroundColor Green
    }
}
```
