## 4. The 5 Rules for On-Page Technical Optimization

### Rule 1: The 60-Word Direct Answer Snippet
Google's algorithms love brevity at the top. When a user searches for a fix, they do not want to read your company's philosophy.
- Place a bold blockquote immediately under your H1 heading.
- State the solution concisely in 40 to 60 words.
- This single formatting decision is how our articles win Google's coveted **Featured Snippet (Position Zero)**.

### Rule 2: Strict Frontmatter Metadata Constraints
- **Title Tag (H1):** Keep strictly under 60 characters. Place the primary keyword phrase as close to the beginning as possible.
- **Meta Description:** Must stay strictly between **140 and 165 characters**. A description longer than 165 characters gets truncated with an ugly ellipsis (`...`) in search results, depressing CTR.
- **Image Alt Text:** Never use generic labels like `screenshot.png` or `laptop.jpg`. Use descriptive text: *"Windows 11 Task Manager displaying memory usage during local AI model inference"*.

### Rule 3: Heading Hierarchy & Keyword Echoing
- Never use more than one `H1` tag per page (your title).
- Use `H2` tags for primary conceptual milestones.
- Ensure at least one `H2` contains your exact target search phrase or a high-volume semantic synonym.
- Lead every `H2` section with a bold summary sentence that answers that subsection's intent.

### Rule 4: E-E-A-T Grounding (Experience & Expertise)
- Write from a first-person team perspective: *"In our workbench tests..."*, *"When we deployed this on our local test server..."*.
- Include reproducible developer artifacts: runnable PowerShell scripts, Python tools, or production `docker-compose.yml` configurations.

### Rule 5: Internal Topical Cluster Linking
- An article without internal links is an orphan page in Google's crawl graph.
- Every new post must link to **3 to 5 existing related articles** within the same topic cluster.
- Always use descriptive anchor text: e.g. `[Windows 11 Bluetooth disappeared fixes](/blog/windows-11-bluetooth-disappeared-not-working-fixes)` rather than generic words.

## 5. Automated Python On-Page SEO Audit Script

**Run our team's standalone Python script to audit any Markdown or MDX article before publishing. It checks title limits, description bounds, heading hierarchy, image alt text, and E-E-A-T markers:**

```python
#!/usr/bin/env python3
"""
scripts/audit_onpage_seo.py
Audits Markdown/MDX articles for on-page SEO compliance, character limits,
direct answer blocks, and E-E-A-T quality signals.
Requires: Python 3.8+ (No external packages required)
"""

import sys
import os
import re

def audit_article(filepath):
    if not os.path.exists(filepath):
        print(f"[ERROR ❌] File not found: {filepath}")
        return

    with open(filepath, "r", encoding="utf-8") as f:
        content = f.read()

    print("=======================================================")
    print(f"🔍 PRAVEENTECHWORLD ON-PAGE SEO AUDIT: {os.path.basename(filepath)}")
    print("=======================================================")

    score = 100
    
    # 1. Frontmatter Title Check (< 60 chars)
    title_match = re.search(r'^title:\s*["\']?(.*?)["\']?$', content, re.MULTILINE)
    if title_match:
        title = title_match.group(1).strip()
        title_len = len(title)
        print(f"• Title: \"{title}\" ({title_len} chars)")
        if title_len > 60:
            score -= 10
            print(f"  [!] Title exceeds 60 chars ({title_len}/60). May truncate in SERPs.")
        else:
            print("  [PASS ✅] Title length is optimal.")
    else:
        score -= 25
        print("  [FAIL ❌] Missing frontmatter title!")

    # 2. Meta Description Check (140 - 165 chars)
    desc_match = re.search(r'^description:\s*["\']?(.*?)["\']?$', content, re.MULTILINE)
    if desc_match:
        desc = desc_match.group(1).strip()
        desc_len = len(desc)
        print(f"• Meta Description: ({desc_len} chars)")
        if desc_len > 165:
            score -= 15
            print(f"  [FAIL ❌] Description exceeds 165 chars ({desc_len}/165). Will be truncated!")
        elif desc_len < 130:
            score -= 5
            print(f"  [!] Description is short ({desc_len}/165). Expand to maximize CTR.")
        else:
            print("  [PASS ✅] Description length is compliant.")
    else:
        score -= 25
        print("  [FAIL ❌] Missing meta description!")

    # 3. Direct Answer Blockquote Check
    if re.search(r'^>\s*\*\*Quick answer:\*\*', content, re.MULTILINE) or re.search(r'^>\s*\*\*Direct answer:\*\*', content, re.MULTILINE):
        print("• Featured Snippet: [PASS ✅] Direct answer callout block detected.")
    else:
        score -= 15
        print("• Featured Snippet: [FAIL ❌] Missing direct answer blockquote in opening!")

    # 4. Code Blocks & Developer Artifacts
    code_blocks = len(re.findall(r'```', content)) // 2
    print(f"• Code Artifacts: {code_blocks} code blocks detected.")
    if code_blocks == 0:
        score -= 15
        print("  [FAIL ❌] Zero code blocks! Technical articles must provide actionable scripts.")
    else:
        print("  [PASS ✅] Contains runnable developer artifacts.")

    # 5. Internal Links Count
    internal_links = len(re.findall(r'\[.*?\]\(/blog/.*?\)', content))
    print(f"• Internal Links: {internal_links} contextual internal links detected.")
    if internal_links < 2:
        score -= 10
        print("  [!] Fewer than 2 internal links. Add cluster cross-links.")
    else:
        print("  [PASS ✅] Strong internal cluster link density.")

    # Final Score Output
    final_score = max(0, score)
    print("-------------------------------------------------------")
    print(f"📊 On-Page SEO Quality Score: {final_score} / 100")
    if final_score >= 90:
        print("[VERDICT 🚀] Ready for Production Release!")
    else:
        print("[VERDICT ⚠️] Address flagged deficiencies before releasing.")
    print("=======================================================")

if __name__ == "__main__":
    test_path = sys.argv[1] if len(sys.argv) > 1 else "src/content/articles/how-to-write-seo-friendly-blog-posts-that-actually-rank-on-google.mdx"
    audit_article(test_path)
```
