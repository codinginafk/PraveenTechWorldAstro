## 3. Step-by-Step Build Blueprint: From Domain to Production

**Follow our team's 5-stage deployment checklist to launch your site with professional engineering standards:**

### Stage 1: Domain Name & DNS Architecture
- **Pick a short, memorable name:** Avoid hyphens, digits, or obscure TLDs. A standard `.com` or `.tech` domain costs between \$10 and \$14 annually from registrars like Cloudflare Registrar or Porkbun.
- **Route DNS through Cloudflare:** Shift your nameservers to Cloudflare's free tier to unlock free enterprise DDoS protection, automatic HTTP/3 acceleration, and DNS-over-HTTPS.

### Stage 2: Establish the 4 Core Content Pages
1. **Homepage:** Immediate value proposition above the fold, primary call-to-action (CTA), and featured work.
2. **About Page:** First-person team story, credentials, workbench methodology, and social proof.
3. **Services / Content Hub:** Clearly structured offerings or blog category pillars with internal cross-links.
4. **Contact Page:** A clean, spam-protected form (using Formspree or Cloudflare Turnstile) rather than a bare mailto link.

### Stage 3: Wireframing and Visual Hierarchy
- **Enforce the 60-30-10 Color Rule:** 60% dominant neutral background (white or charcoal), 30% secondary structure (cards and borders), and 10% high-contrast accent color for interactive CTA buttons.
- **Typography Limit:** Limit font families to maximum 2: one high-readability sans-serif for body copy (Inter, Roboto) and one distinctive font for headings.

## 5. DNS Configuration Guide: Connecting Your Custom Domain

**To connect your domain to a free hosting platform (Cloudflare Pages or Vercel), configure these standard DNS records in your domain control panel:**

| Record Type | Host / Name | Target / Destination Value | Proxy Status | Purpose |
|---|---|---|:---:|---|
| **CNAME** | `@` (Root) | `your-site-name.pages.dev` | **Proxied (Orange Cloud)** | Directs root domain traffic to edge CDN nodes |
| **CNAME** | `www` | `your-site-name.pages.dev` | **Proxied (Orange Cloud)** | Ensures `www.example.com` resolves seamlessly |
| **TXT** | `@` | `v=spf1 ~all` | DNS Only | Prevents unauthorized email spoofing of your domain |
| **TXT** | `_dmarc` | `v=DMARC1; p=none;` | DNS Only | Establishes basic DMARC email security compliance |

## 6. Pre-Flight Technical Launch Checklist

**Never hit publish without validating these 5 technical quality gates:**

| Launch Gate | Verification Method | Target Benchmark | Common Beginner Pitfall |
|---|---|---|---|
| **1. SSL / HTTPS Enforcement** | Inspect URL protocol in browser | `https://` with valid padlock | Mixed-content warnings from hardcoded `http://` image URLs |
| **2. Mobile Viewport Scaling** | Chrome DevTools (Ctrl+Shift+M) | Zero horizontal scrolling | Fixed-pixel widths (`width: 1200px`) breaking phone viewports |
| **3. XML Sitemap & Robots.txt** | Navigate to `/sitemap-index.xml` | Returns clean 200 HTTP code | Blocking Googlebot accidentally with `Disallow: /` in robots.txt |
| **4. Core Web Vitals Audit** | Run Google PageSpeed Insights | **Performance score > 90** | Uncompressed 5MB hero images destroying Largest Contentful Paint |
| **5. Google Analytics 4 Verify** | Check GA4 Realtime Dashboard | Active user registered on click | Forgetting to verify measurement ID after DNS propagation |
