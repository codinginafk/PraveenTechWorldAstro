When a PC experiences random reboots, application hangs, or unexplainable file corruption, the primary hardware suspect is **faulty System Memory (RAM)**.

Because RAM handles volatile data operations for every active application, a single failing memory cell can corrupt files, crash graphics drivers, or trigger repeating **Blue Screen of Death (BSOD)** errors.

Our bench team follows a strict, step-by-step diagnostic protocol to separate defective RAM modules from motherboard slot failures and driver corruptions. Here is how to test your RAM like a sysadmin.

---

## ⚡ Fast PowerShell Query: Inspect Physical RAM Modules

To inspect your RAM specifications, speed, and hardware part numbers without opening your PC case, run this PowerShell command:

```powershell
# Query RAM slot assignment, capacity, and manufacturer specs
Get-CimInstance Win32_PhysicalMemory | 
Select-Object BankLabel, @{N='Capacity (GB)';E={$_.Capacity/1GB}}, Speed, Manufacturer, PartNumber
```bash

This output displays the exact slot placement (e.g. `BANK 0`, `BANK 2`), speed (MHz/MT/s), and manufacturer (Samsung, SK Hynix, Micron).

## 📋 5 Warning Signs of Failing RAM

| # | Symptom | Typical Manifestation | Quick Check |
|:---|:---|:---|:---|
| **1** | **Motherboard Beep Codes / Q-LED** | Repeated POST beep codes or lit DRAM LED on motherboard | Check motherboard manual for DRAM POST error pattern |
| **2** | **Random System Freezes** | Cursor locks and UI freezes under heavy memory load | Run MemTest86 overnight |
| **3** | **Repeating BSODs** | Stop codes `0x1A (MEMORY_MANAGEMENT)` or `0x50` | Extract minidump logs in PowerShell |
| **4** | **Silent File Corruption** | Zip archive CRC errors or saved files becoming unreadable | Run `chkdsk /f` on boot volume |
| **5** | **Chrome / Edge "Aw Snap!"** | Browser tabs crashing constantly with memory access errors | Test single RAM stick isolation |

## Step 1: Hardware Reseat & Slot Isolation Protocol

Before running long software scans, perform a physical hardware isolation test:

```text
[ Test Single Stick ] ──► Insert into Slot A2 ──► Run Diagnostic
                                 │
       ┌─────────────────────────┴─────────────────────────┐
       ▼                                                   ▼
Single Stick Passes                                Single Stick Fails
• Move stick to Slot B2 to test slot integrity     • Wipe gold contacts with 99% IPA
• Repeat for Stick #2                              • Retest; if failure recurs, RMA stick
```bash

1. **Unplug Power & Ground Yourself:** Drain residual power by holding the power button for 15 seconds after unplugging the PSU.
2. **Pull All DIMMs:** Inspect gold contacts for oxidation. Clean contacts gently using 99% Isopropyl Alcohol (IPA).
3. **Test One Stick at a Time:** Insert **Stick #1 into Slot A2** (refer to your motherboard manual for the primary single-DIMM slot).
4. Boot into Windows and run a quick test. If it passes, move Stick #1 to Slot B2 to rule out a damaged motherboard slot.

---

## Step 2: Run Windows Memory Diagnostic (`mdsched.exe`)

Windows includes a built-in memory diagnostic tool for quick preliminary testing:

1. Press **Win + R**, type `mdsched.exe`, and press **Enter**.
2. Click **Restart now and check for problems (recommended)**.
3. Your PC will reboot into a blue diagnostic screen. Let the test complete 100%.

> ⚠️ **Note:** Windows Memory Diagnostic is a quick sanity check. Passing `mdsched.exe` does **not** guarantee 100% RAM stability. For definitive testing, proceed to MemTest86.

---

## Step 3: Run MemTest86 (The Gold Standard Test)

PassMark **MemTest86** is an OS-agnostic testing tool that runs from a bootable USB drive, writing complex data patterns across every raw memory block.

1. Download the free edition of MemTest86 and create a bootable USB using their image tool.
2. Plug the USB into your target PC and boot into the USB via the boot menu (`F12` or `DEL`).
3. Select **Run MemTest86 (Standard)**.
4. Allow the test to complete **4 full passes** (takes 3 to 5 hours).

```text
MemTest86 Pass Summary:
- 0 Errors Found  ──► RAM hardware is 100% Healthy (Problem is a Driver or OS file).
- 1+ Errors Found ──► RAM hardware is Defective (Replace or RMA memory kit).
```

---

## Step 4: Disable XMP / EXPO Memory Overclocks

If MemTest86 reports errors, your RAM kit may not be physically broken—it may simply be unstable under **XMP (Intel)** or **EXPO (AMD)** overclock profiles.

1. Enter your motherboard BIOS/UEFI on boot (`DEL` or `F2`).
2. Locate **XMP / EXPO / DOCP** settings.
3. Set the profile to **Disabled** (reverting RAM to JEDEC base speeds, e.g. 4800 MT/s).
4. Save settings and re-run MemTest86. If errors disappear, your CPU's Integrated Memory Controller (IMC) requires a slight VDD/SOC voltage tweak or a BIOS microcode update to sustain high XMP speeds.
