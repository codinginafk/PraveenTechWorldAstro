If you run local LLMs with Ollama on Windows or Linux, you have likely experienced this frustrating issue: **The model starts fast (40+ tokens/sec), but after 10–15 minutes of chatting, inference slows to a crawl (3-5 tokens/sec) and system fans spin up.**

When you open Task Manager or `nvidia-smi`, you notice GPU usage dropped from 95% down to 20%, while CPU usage spiked.

On our IT operations workbench, we ran extensive diagnostics on an RTX 3060 running DeepSeek R1-8B. Here is why this GPU offload regression happens, how to verify it with `ollama ps`, and the 3 environment variables that keep inference 100% on the GPU.

---

## Why Does Ollama Offload Layers Back to CPU?

When you initiate a chat session, Ollama dynamically calculates VRAM usage based on:
1. **Model Weight Size:** (e.g., 4.9 GB for Q4_K_M 8B model)
2. **Context Window Allocation (`num_ctx`):** KV cache memory allocation.

By default, Ollama assigns a standard `num_ctx` of 2,048 or 4,096 tokens. As your conversation history grows, KV cache memory scales linearly. When KV memory exceeds available VRAM headroom, Ollama's `llama.cpp` backend **silently offloads model layers from VRAM to System RAM (CPU)** to prevent an out-of-memory crash.

---

## 🛠️ Step 1: Diagnose With `ollama ps`

While your slow chat session is active, open a terminal and run:

```bash
ollama ps
```

### Sample Faulty Output:
```text
NAME             ID           SIZE     PROCESSOR        UNTIL
deepseek-r1:8b   a1b2c3d4e5   5.2 GB   65%/35% CPU/GPU  4 minutes
```

If the `PROCESSOR` column shows `CPU/GPU` split (e.g., `65%/35% CPU/GPU`), Ollama has demoted 65% of the model layers off your graphics card!

---

## 🛠️ Step 2: Apply the 3-Line Environment Variable Fix

To prevent memory spillover and force Flash Attention + optimized KV cache compression, set these 3 environment variables on your system:

### Windows (PowerShell System-Wide):
```powershell
[System.Environment]::SetEnvironmentVariable('OLLAMA_FLASH_ATTENTION', '1', 'Machine')
[System.Environment]::SetEnvironmentVariable('OLLAMA_KV_CACHE_TYPE', 'q8_0', 'Machine')
[System.Environment]::SetEnvironmentVariable('OLLAMA_NUM_PARALLEL', '1', 'Machine')
```

### Linux / macOS:
```bash
export OLLAMA_FLASH_ATTENTION=1
export OLLAMA_KV_CACHE_TYPE=q8_0
export OLLAMA_NUM_PARALLEL=1
```
